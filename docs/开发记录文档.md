### 1.1 文档用途

- **过程追溯**：记录每个开发阶段的任务完成情况、遇到的问题与解决方案，便于后续回溯。
- **风险管控**：动态跟踪项目风险与已知问题，及时识别并应对。
- **决策留痕**：记录架构选型、技术选型等关键决策，保留决策依据，避免重复讨论。
- **质量保障**：通过 Code Review 记录、版本里程碑记录，保障代码质量与版本可控。
- **复盘参考**：为后续版本迭代、新成员入职、技术沉淀提供原始资料。

### 1.2 文档使用约定

- 所有日期统一使用 `YYYY-MM-DD` 格式，时间使用 `YYYY-MM-DD HH:mm` 格式。
- 工时单位为「人时（PH）」或「人天（PD）」，填写时需注明。
- 状态字段统一取值：`未开始 / 进行中 / 已完成 / 已阻塞 / 已暂停 / 已取消`。
- 优先级字段统一取值：`高 / 中 / 低`。
- 风险等级统一取值：`高 / 中 / 低`。
- 文档由项目开发组共同维护，每日开发结束前更新当日记录。

### 1.3 项目技术栈概览

| 维度 | 技术选型 |
| --- | --- |
| 开发语言 | Kotlin（纯 Kotlin，禁止混入大量 Java） |
| 基础架构 | Jetpack（Lifecycle、ViewModel、Flow、DataBinding、Navigation）+ MVVM |
| 异步方案 | Kotlin 协程 + Flow（禁止 Thread/Handler/RxJava） |
| 播放内核 | ExoPlayer（全局单例 + 多实例播放器池） |
| 音视频处理 | FFmpeg（辅助能力：格式兼容、截取、转码、帧提取） |
| 弹幕框架 | DanmakuFlameMaster |
| 网络层 | OkHttp（单例 + 拦截器 + 连接池复用） |
| 安全加密 | AES-128-CBC（传输加密 + 本地缓存加密 + 动态密钥） |
| 业务形态 | 长视频 / 抖音式短视频 / 本地视频 |
| 五大主页 | 首页（短视频Feed流）/ 发现页 / 排行榜 / 找片 / 我的 |
