## 一、文档说明

### 1.1 项目概述

追剧 APP（zhuiju）是一款 Android 原生商用级视频播放 APP，定位为长视频点播 + 抖音式短视频 + 本地视频播放三位一体的综合视频内容平台。包含「首页（短视频 Feed 流）/ 发现页 / 排行榜 / 找片 / 我的」五大主页，满足用户沉浸式观影、内容发现、热度浏览、精准检索、个人管理的全场景诉求。

### 1.2 技术栈

| 层级 | 技术选型 | 用途说明 |
| --- | --- | --- |
| 开发语言 | Kotlin（纯 Kotlin，禁止混入大量 Java） | 主开发语言 |
| 基础架构 | Jetpack（Lifecycle / ViewModel / Flow / DataBinding / Navigation） | MVVM 架构、生命周期、状态管理 |
| 异步调度 | Kotlin 协程 + Flow | 全局唯一异步方案，禁用 Thread/Handler/RxJava |
| 播放器内核 | ExoPlayer | 长视频/短视频核心播放、HLS/DASH/MP4/FLV 兼容、分片缓存 |
| 辅助音视频 | FFmpeg | 异常格式兼容、视频截取、帧提取、短视频裁剪、视频修复 |
| 弹幕渲染 | DanmakuFlameMaster | B 站开源弹幕框架，加载/滚动/屏蔽/同步 |
| 网络层 | OkHttp | 网络请求、视频分片下载、断点续传、拦截器 |
| 加密安全 | AES-128-CBC | 视频分片加密、本地缓存加密、接口数据加密 |
| 架构模式 | MVVM + Repository 分层 | View → ViewModel → Repository → 数据源 |

### 1.3 文档目的

1. 明确项目全量开发任务清单，统一研发口径；
2. 建立任务分级体系（P0/P1/P2），优先级清晰可控；
3. 通过分阶段落地流程，确保 5 个阶段按时交付；
4. 提供任务依赖关系说明，规避阻塞返工；
5. 提供任务状态跟踪表与验收标准，便于进度可视化管理。

## 二、任务分级体系

| 优先级 | 等级名称 | 定义 | 验收要求 |
| --- | --- | --- | --- |
| **P0** | 核心任务 | 项目上线必备能力，直接影响 APP 核心功能可用性（播放、加密、五大主页） | 必须完成，100% 验收通过，否则不予上线 |
| **P1** | 重要任务 | 重要增强能力，影响用户体验与商业安全（缓存、弹幕、UI、性能、适配） | 必须完成，关键场景验收通过 |
| **P2** | 增强任务 | 体验增强与锦上添花能力（高级动画、低端机降级细节、辅助工具） | 视进度与资源情况推进，不阻塞上线 |

## 四、分阶段开发落地流程（5 阶段）

### 阶段一：基础架构搭建与环境集成（1~2 天）

**阶段目标**：完成项目初始化、技术栈全部依赖集成、基础封装，可正常编译运行。

**工作内容**：
1. 创建 Kotlin 项目，配置 Gradle，引入 Jetpack、ExoPlayer、FFmpeg、DanmakuFlameMaster、OkHttp 全部依赖；
2. 搭建 MVVM 基础架构、基类封装、协程与 Flow 基础配置；
3. 封装 OkHttp 网络框架、全局异常拦截、日志工具；
4. 开发 AES 加密基础工具类、密钥管理基础逻辑；
5. 权限管理、全局工具类、全局常量、主题色值初始化。

**交付物**：可编译项目架构、基础工具类、网络框架、加密工具可用。

**验收标准**：
- 项目编译通过，无报错；
- 依赖全部集成成功，无版本冲突；
- OkHttp 单例可发起测试请求；
- AES 工具类可完成加解密自测；
- BaseActivity/BaseFragment/BaseViewModel 模板可用。

**涉及任务**：ARCH-001 ~ ARCH-011、NET-001、ENC-001、ENC-002

---

### 阶段二：核心播放器能力开发（2~3 天）

**阶段目标**：实现完整视频播放核心能力，满足基础点播需求。

**工作内容**：
1. 封装全局单例 ExoPlayer 管理器，绑定页面生命周期；
2. 开发基础播放、暂停、进度拖拽、多格式播放能力；
3. 实现倍速、静音、循环、记忆播放位置功能；
4. 适配 HLS / MP4 / FLV 主流视频格式；
5. 开发播放异常重试、错误提示机制；
6. 完成横竖屏切换、手势控制交互；
7. 开发短视频播放器池、首帧极速渲染、音频焦点管理。

**交付物**：独立可用的视频播放器组件，可正常播放在线/本地视频；短视频池可上下滑动无缝切换。

**验收标准**：
- 在线/本地视频可正常播放，无黑屏花屏；
- 倍速/静音/循环/记忆进度功能正常；
- 横竖屏切换进度不丢失，无画面拉伸；
- 手势调节亮度/音量/进度正常反馈；
- 短视频上下滑动无黑屏，首帧 <100ms；
- 异常重试 3 次后展示错误弹窗，不崩溃。

**涉及任务**：PLAY-001 ~ PLAY-018

---

### 阶段三：缓存、FFmpeg 辅助、弹幕功能开发（2~3 天）

**阶段目标**：完善视频辅助能力，实现弹幕交互、格式兼容、离线缓存。

**工作内容**：
1. 集成 FFmpeg，完成特殊视频格式兼容、帧截图、封面提取功能；
2. 开发 ExoPlayer 离线分片缓存、断点续传、缓存管理功能；
3. 集成 DanmakuFlameMaster，实现弹幕加载、同步、渲染展示；
4. 开发弹幕设置功能，适配倍速、拖拽状态同步；
5. 优化弹幕性能，解决卡顿、堆积问题。

**交付物**：支持离线缓存、全格式兼容、完整弹幕交互的播放器。

**验收标准**：
- ExoPlayer 硬解失败视频可由 FFmpeg 软解成功播放；
- 视频帧截图、封面提取功能正常；
- 分片缓存断点续传正常，缓存清理功能可用；
- 弹幕与播放进度同步，拖拽/倍速/暂停无错位堆积；
- 弹幕开关、透明度、字号、颜色设置生效；
- 单屏弹幕 ≤80 条，低端机降级正常。

**涉及任务**：FF-001 ~ FF-007、PLAY-007、PLAY-008、PLAY-013、PLAY-014、DAN-001 ~ DAN-010

**交付物**：具备完整安全防护能力的视频播放系统。

**验收标准**：

- 密钥 24 小时自动更新成功；
