## 1. 文档说明

### 1.1 编写目的

本文档用于记录追剧 APP（zhuiju）在研发、联调、预发布及上线前各阶段的测试活动，包括测试策略、用例清单、执行记录、缺陷跟踪、性能与兼容性结果、上线验收清单及测试报告。目的为：

- 规范测试流程，确保各核心功能模块均被覆盖；
- 沉淀测试资产，便于版本迭代回归；
- 提供质量评估依据，支撑上线决策；
- 对照源文档验收标准逐项核对，确认无黑屏/花屏/卡顿/内存泄漏/ANR，弹幕同步精准，加密有效，缓存断点续传正常，高低端机型适配达标。

### 1.2 适用范围

- 适用对象：追剧 APP Android 客户端（Kotlin + Jetpack 架构）。
- 覆盖模块：长视频点播、抖音式短视频 Feed 流、本地视频、弹幕、缓存、AES-128-CBC 加解密、手势交互、横竖屏切换、五大主页（首页/发现/排行榜/找片/我的）。
- 适用阶段：SIT 集成测试、UAT 验收测试、上线前回归测试。

### 1.3 测试环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Android 8.0 (API 26) 及以上，覆盖至 Android 14 (API 34) |
| 测试网络 | Wi-Fi / 4G / 5G / 弱网（丢包 20%、延迟 300ms、带宽 64kbps） |
| 服务端 | 预发布环境（与生产同构），后端 API 已通过自测 |
| 测试账号 | 包含游客、普通用户、VIP 用户、异常账号（封禁/欠费）各 1 套 |
| 测试数据 | 涵盖长视频（≥ 90min）、短视频（15~60s）、本地 mp4/mkv、加密分片 ts |
| 依赖工具 | Android Studio、adb、Charles/Fiddler、PerfDog、LeakCanary、Monkey、GT |
| 证书 | 正式签名包 + 调试包；加密密钥使用预发布环境密钥 |

## 3. 测试策略与阶段

### 3.1 测试阶段划分

| 阶段 | 责任方 | 准入条件 | 准出条件 | 交付物 |
| --- | --- | --- | --- | --- |
| 单元测试（UT） | 开发 | 模块代码自测通过 | 核心类覆盖率 ≥ 70% | 单测报告、覆盖率截图 |
| 集成测试（SIT） | 测试 | 模块联调包可用 | P0/P1 用例 100% 通过 | 集成测试报告 |
| 功能测试 | 测试 | SIT 准出 | 全部 P0~P2 用例通过率 ≥ 95% | 功能测试报告、缺陷库 |
| 兼容性测试 | 测试 | 功能测试通过 | 机型矩阵通过率 ≥ 90% | 兼容性矩阵 |
| 性能测试 | 测试 | 功能稳定 | 满足性能基线（见第 7 节） | PerfDog 性能报告 |
| 安全测试 | 安全 + 测试 | 加密功能完成 | 无密钥泄露、抓包不可解 | 安全测试报告 |
| 用户体验测试（UAT） | 产品 + 测试 | 全功能可用 | 用户验收签字 | UAT 报告 |
| 上线前回归 | 测试 | Bug 修复完成 | 验收 Checklist 全部通过 | 上线测试报告 |

### 3.2 测试方法

- **黑盒功能测试**：等价类、边界值、场景法覆盖五大主页与播放器交互。
- **白盒/灰盒测试**：针对 ExoPlayer 缓存、AES 解密链路进行日志断点分析。
- **自动化测试**：核心播放/短视频 Feed 流用 Espresso + UIAutomator 编写回归脚本。
- **性能测试**：PerfDog 采集 CPU、内存、FPS、耗电；LeakCanary 监控内存泄漏。
- **稳定性测试**：Monkey 7×24h 随机事件压测，最长 12h 无 ANR/Crash。
- **弱网测试**：Charles 模拟 64kbps / 300ms 延迟 / 20% 丢包。
- **安全测试**：抓包验证密文不可解、反编译检查密钥硬编码、本地缓存文件加密。
