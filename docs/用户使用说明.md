## 一、欢迎与产品简介

### 1.1 欢迎使用

欢迎使用追剧APP！这是一款让您随时随地看视频的手机应用。无论您喜欢追剧、刷短视频，还是想回看本地视频，追剧APP都能满足您的需求。

### 1.2 追剧APP能做什么

追剧APP为您提供以下核心体验：

| 功能 | 说明 |
| --- | --- |
| 长视频点播 | 电影、电视剧、综艺、动漫等长视频，支持选集、倍速、弹幕、横屏全屏观看 |
| 短视频刷不停 | 抖音式上下滑动刷短视频，双击点赞，边看边评论 |
| 本地视频播放 | 播放您手机里自己的视频文件 |
| 离线缓存 | 没网络也能看，提前把视频缓存到手机 |
| 弹幕互动 | 边看边和网友互动，弹幕可开关、可调样式 |
| 安全加密 | 视频内容加密保护，看视频更安心 |

### 1.3 五大主页一览

打开APP后，您会在屏幕底部看到五个主入口：

| 主页 | 一句话用途 |
| --- | --- |
| 首页 | 上下滑动刷短视频 |
| 发现 | 浏览热门推荐内容 |
| 排行榜 | 查看日榜、周榜、月榜 |
| 找片 | 搜索视频、按分类找内容 |
| 我的 | 个人中心、我的作品/收藏/喜欢、设置 |

> 💡 **小贴士**：底部导航栏的五个图标在任何主页都能看到，点一下就能切换页面。

## 二、安装与卸载说明

### 2.1 系统要求

为了让追剧APP运行流畅，您的手机需要满足以下条件：

| 项目 | 要求 |
| --- | --- |
| 手机系统 | Android 7.0 及以上（推荐 Android 10.0 及以上获得完整体验） |
| 运行内存 | 建议 3GB 以上；刷短视频建议 4GB 以上 |
| 存储空间 | 安装需预留 200MB 以上；缓存视频建议预留 5GB 以上 |
| 网络 | 支持 WiFi、4G、5G |

### 2.2 安装步骤

1. 从官方应用商店或官方提供的下载链接获取追剧APP安装包。
2. 点击下载完成的安装包，弹出安装提示。
3. 如果系统提示「出于安全考虑，禁止安装未知来源应用」，请按提示前往设置，允许从该来源安装应用。
4. 点击「安装」，等待安装完成。
5. 安装完成后，点击「打开」即可启动APP；或在桌面找到「追剧」图标点击进入。

> ⚠️ **注意**：请务必从官方渠道下载安装包，不要安装来历不明的版本，以免手机安全受到威胁。

### 2.3 卸载说明

如果您不再使用追剧APP，可以通过以下方式卸载：

1. 在手机桌面长按「追剧」图标。
2. 在弹出的菜单中选择「卸载」或「删除」。
3. 确认卸载即可。

> 💡 **小贴士**：卸载APP会自动清除APP内的缓存数据。如果想彻底清理，可在卸载前到「我的 → 设置 → 清理缓存」中先清理一遍。

## 三、首次使用引导

### 3.1 首次打开

1. 在桌面找到「追剧」图标，点击打开。
2. 首次启动会显示品牌启动动画，请稍候片刻。
3. 进入APP后，默认停留在「首页」，即短视频播放页面，会自动静音播放第一条视频。

### 3.2 权限授权说明

为了让追剧APP正常工作，首次使用时会按需向您申请以下权限。您可以放心授权，APP不会过度索取权限。

| 权限名称 | 申请时机 | 用途说明 |
| --- | --- | --- |
| 网络权限 | 首次启动 | 用于播放在线视频、加载内容 |
| 通知权限 | 首次使用后台播放时 | 用于在通知栏显示播放状态，方便后台继续听声音 |
| 存储权限 | 首次使用本地视频/缓存时 | 用于读取您手机里的视频、保存缓存视频 |
| 悬浮窗权限 | 首次使用小窗播放时 | 用于在其他应用上方显示小窗播放画面 |

> ⚠️ **注意**：每个权限申请时都会有弹窗说明用途，您可以选择「允许」或「拒绝」。即使拒绝部分权限，您依然可以正常使用基础播放功能；当您用到对应功能时，APP会再次友好地引导您开启。

### 3.3 首页初体验

- 进入首页后，第一条短视频会自动静音播放。
- 想听声音？点击屏幕右侧的「音量」图标即可取消静音。
- 想看下一个视频？用手指上下滑动即可切换。
- 详细操作请见 [第六章 短视频操作指南](#六短视频操作指南)。

## 四、五大主页使用指南

### 4.1 首页：刷短视频

**用途**：首页是APP的核心页面，为您提供源源不断的短视频内容，上下滑动即可刷不停。

**怎么用**：

1. 打开APP默认进入首页，第一条短视频会自动静音播放。
2. 用手指**向上滑动**屏幕，看下一个视频；**向下滑动**，回到上一个视频。
3. **单击**屏幕可暂停或继续播放，同时会显示/隐藏右侧的功能按钮。
4. **双击**屏幕可以点赞，会出现红色爱心动画。
5. 屏幕右侧有一排功能按钮，从上到下通常是：

| 按钮 | 作用 |
| --- | --- |
| 头像 | 点击进入作者主页，可关注作者 |
| 点赞（爱心） | 点赞当前视频 |
| 评论 | 查看和发表评论 |
| 收藏 | 收藏当前视频，方便以后回看 |
| 分享 | 分享给好友 |
| 音量 | 切换静音/有声 |

> 💡 **小贴士**：首页短视频默认静音播放，是为了不打扰您。想听声音时点一下右侧音量按钮即可，APP会记住您的选择。

### 4.2 发现页：浏览热门推荐

**用途**：发现页为您推荐当下最热门、最值得看的内容，帮您发现好视频。

**怎么用**：

1. 点击底部导航栏「发现」进入。
2. 顶部会看到滚动的横幅广告或活动推荐，点击可进入对应活动。
3. 下方是分类标签（如影视、综艺、动漫等），左右滑动可切换分类。
4. 主体是双列卡片瀑布流，上下滑动浏览推荐内容。
5. 看到感兴趣的视频，点击卡片即可进入播放页。
6. 顶部下拉可刷新内容，滑到底部会自动加载更多。

> 💡 **小贴士**：不知道看什么的时候，就来发现页逛逛，总会有惊喜。

### 4.3 排行榜：查看热门榜单

**用途**：排行榜展示每天、每周、每月最火的内容，让您紧跟潮流不迷路。

**怎么用**：

1. 点击底部导航栏「排行榜」进入。
2. 顶部有「日榜」「周榜」「月榜」三个标签，点击切换。
3. 列表会按热度从高到低排列，前三名会有金银铜牌特殊样式。
4. 每条榜单展示排名、封面、标题、热度等信息。
5. 点击列表项可直接进入播放页观看。
6. 如果榜单里有喜欢的作者，可以点击「关注」按钮关注他。
7. 顶部下拉可刷新榜单获取最新排名。

| 榜单类型 | 更新频率 | 适合场景 |
| --- | --- | --- |
| 日榜 | 每天更新 | 看今天最火的内容 |
| 周榜 | 每周更新 | 看本周热门趋势 |
| 月榜 | 每月更新 | 回顾本月经典 |

### 4.4 找片：搜索和分类

**用途**：找片页帮您快速找到想看的视频，可以搜索关键词，也可以按分类浏览。

**怎么用**：

1. 点击底部导航栏「找片」进入。
2. 顶部搜索框中输入视频名称或关键词，输入时会自动联想建议。
3. 点击键盘上的「搜索」或回车键，查看搜索结果。
4. 不知道搜什么？看看搜索框下方的「热门搜索」，点击标签直接搜索。
5. 下方「历史搜索」记录您搜过的词，可单条删除或一键清空。
6. 不搜索时，页面下方展示所有分类（如电影、电视剧、综艺、动漫、游戏、生活、美食等），点击分类查看该分类下的内容。
7. 各分类下还有横向滚动的推荐卡片，左右滑动浏览。

> 💡 **小贴士**：搜索结果支持按分类、时长、画质进行筛选，帮您更快找到心仪的视频。退出搜索点返回键即可回到分类浏览状态。

### 4.5 我的：个人中心

**用途**：「我的」是您的个人主页，展示您的资料、作品、收藏和喜欢的内容，也是进入设置的入口。

**怎么用**：

1. 点击底部导航栏「我的」进入。
2. 顶部展示您的头像、昵称、简介，以及获赞、关注、粉丝等数据。
3. 上下滑动可让顶部头部收缩或展开，动效流畅。
4. 下方有四个标签页，左右滑动或点击切换：

| 标签 | 内容 |
| --- | --- |
| 作品 | 您自己发布的视频作品 |
| 私密 | 仅您自己可见的私密作品 |
| 收藏 | 您收藏过的视频 |
| 喜欢 | 您点过赞的视频 |

5. 点击任意视频卡片可进入播放页。
6. 页面底部有「设置」入口，点击进入设置页（详见 [第八章 设置说明](#八设置说明)）。

> ⚠️ **注意**：如果某个标签下没有内容，会显示空状态提示，属于正常现象。

## 五、长视频播放操作指南

长视频（电影、电视剧、综艺等）的播放页功能丰富，请按以下说明使用。

### 5.1 播放、暂停与拖拽进度

| 操作 | 怎么做 |
| --- | --- |
| 播放 / 暂停 | 点击屏幕中央，或点击控制栏中间的播放/暂停按钮 |
| 拖拽进度 | 用手指按住底部进度条左右拖动，松手后从新位置继续播放 |
| 显示/隐藏控制栏 | 单击屏幕一次，控制栏（含播放按钮、进度条等）会显示或隐藏 |

> 💡 **小贴士**：控制栏如果3秒内没有任何操作会自动隐藏，让您专注观看。播放超过3秒后，APP会自动记住您的播放进度，下次打开同视频会从上次位置继续。

### 5.2 倍速播放

追剧APP支持 **0.5x ~ 5.0x** 的倍速播放，共13个档位，方便您快进慢看。

| 倍速 | 适合场景 |
| --- | --- |
| 0.5x / 0.75x | 慢放学习、看细节 |
| 1.0x | 正常速度 |
| 1.25x / 1.5x / 1.75x / 2.0x | 稍微加速追剧 |
| 2.5x ~ 5.0x | 快速浏览、跳过冗长内容 |

**怎么设置倍速**：

1. 单击屏幕唤起控制栏。
2. 点击控制栏上的「倍速」按钮。
3. 在弹出的倍速列表中选择您想要的速度。

> 💡 **小贴士**：长按屏幕可临时切换到2倍速，松手后自动恢复原速度，适合快速跳过不重要的片段。

### 5.3 手势操作（亮度/音量/进度）

在横屏全屏状态下，您可以用手势快速调节画面，无需找按钮：

| 手势区域 | 手势方向 | 功能 |
| --- | --- | --- |
| 屏幕左半边 | 上下滑动 | 调节屏幕亮度（上滑变亮，下滑变暗） |
| 屏幕右半边 | 上下滑动 | 调节音量大小（上滑变大，下滑变小） |
| 整个屏幕 | 左右滑动 | 拖拽播放进度（右滑快进，左滑后退） |

文字图示如下：

```
        ┌─────────────┬─────────────┐
        │             │             │
        │   左侧       │   右侧       │
        │   上下滑     │   上下滑     │
        │   调亮度     │   调音量     │
        │             │             │
        └─────────────┴─────────────┘
              左右滑 →  拖进度
```

滑动时屏幕中央会出现实时提示（如亮度条、音量条、跳转时间），方便您看到当前数值。

> 💡 **小贴士**：手势操作有最小滑动距离限制，轻微移动不会误触发，您可以放心使用。

### 5.4 横竖屏切换

- 长视频默认竖屏半屏播放。
- 想要全屏观看？有两种方式：
  1. 点击控制栏上的「全屏」按钮。
  2. 直接把手机横过来（需开启手机自动旋转）。
- 横屏全屏时画面会自动避开刘海/挖孔区域，进度不会丢失，切换过程流畅无闪烁。
- 想退出全屏？再点一次「全屏」按钮，或把手机竖回来即可。

> ⚠️ **注意**：如果横屏不自动切换，请检查手机系统的「自动旋转」开关是否打开。

### 5.5 弹幕开关与设置

弹幕让您和其他观众一起看视频，边看边聊。您可以自由控制弹幕的显示效果。

**开关弹幕**：单击屏幕唤起控制栏，点击「弹幕」按钮即可开/关弹幕。

**弹幕设置**：长按或点击弹幕按钮，会弹出底部设置面板，可调整以下内容：

| 设置项 | 说明 |
| --- | --- |
| 弹幕开关 | 一键开/关弹幕 |
| 字号 | 小 / 默认 / 大，三种字号可选 |
| 透明度 | 0（完全透明）~ 1（完全不透明），默认半透明 |
| 颜色 | 白 / 黄 / 红 / 绿 / 蓝，可选自己喜欢的颜色 |
| 屏蔽 | 可屏蔽顶部弹幕、底部弹幕，或按关键词屏蔽不想看的弹幕 |

> 💡 **小贴士**：弹幕太多看不清画面？把透明度调低一点，或者开启屏蔽功能。APP会根据手机性能自动控制弹幕数量，保证画面流畅。

### 5.6 选集、画质与缓存

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| 选集 | 控制栏「选集」按钮 | 电视剧、综艺有多集，点击查看集列表，选择想看的集数 |
| 画质 | 全屏状态下「画质」按钮 | 可选 720P / 1080P / 4K，网络好选高清，网络差选标清 |
| 缓存 | 控制栏「缓存」按钮 | 加入离线下载队列，没网络也能看（详见第七章） |

> ⚠️ **注意**：4K 画质需要视频本身支持，且消耗较多流量，建议在 WiFi 下使用。

## 六、短视频操作指南

短视频在「首页」播放，操作简单直观，符合抖音等主流APP的使用习惯。

### 6.1 上下滑动看视频

- **向上滑动**：看下一个视频，切换流畅无黑屏。
- **向下滑动**：回到上一个视频。

### 6.2 单击与双击

| 操作 | 作用 |
| --- | --- |
| 单击屏幕 | 暂停 / 继续播放，同时显示或隐藏右侧功能按钮 |
| 双击屏幕 | 点赞，会出现红色爱心粒子动画 |

### 6.3 右侧按钮功能

从上到下依次是：

| 按钮 | 作用 |
| --- | --- |
| 头像 | 进入作者主页，可查看作者其他作品并关注 |
| 点赞（爱心） | 给当前视频点赞 |
| 评论 | 打开评论区，可查看评论、发表评论、回复他人 |
| 收藏 | 收藏视频，在「我的 → 收藏」可找到 |
| 分享 | 调起系统分享，可分享给微信、QQ等好友 |
| 音量 | 切换静音 / 有声，APP会记住您的选择 |

### 6.4 评论、分享与关注

- **发表评论**：点击右侧「评论」按钮，弹出评论区，在底部输入框输入文字后发送。
- **分享视频**：点击「分享」按钮，选择要分享到的应用（微信、QQ、微博等）。
- **关注作者**：点击右侧头像或「关注」按钮，即可关注该作者，后续可在「我的 → 关注」查看更新。

### 6.5 静音切换

- 首页短视频默认静音播放，避免打扰。
- 点击右侧「音量」按钮可切换有声/静音。
- 您的选择会被记住，切换到其他视频后保持一致。

> 💡 **小贴士**：切到后台或接电话时，短视频会自动暂停；回到APP后会自动继续播放，不用手动恢复。

## 七、离线缓存使用说明

离线缓存让您提前把视频下载到手机，没网络时也能看，还省流量。

### 7.1 如何缓存视频

1. 在视频播放页，单击屏幕唤起控制栏。
2. 点击控制栏上的「缓存」按钮。
3. 选择要缓存的集数和画质（电视剧可选多集）。
4. 确认后视频加入下载队列，开始后台下载。
5. 下载过程中您可以继续看其他视频，不影响使用。

> 💡 **小贴士**：建议在 WiFi 环境下缓存，避免消耗手机流量。

### 7.2 缓存管理

缓存管理入口：「我的 → 离线缓存」。

在这里您可以看到所有已缓存和正在缓存的视频列表，每条显示：

| 信息 | 说明 |
| --- | --- |
| 缩略图 | 视频封面 |
| 标题 | 视频名称 |
| 大小 | 占用手机空间 |
| 缓存时间 | 下载完成的时间 |
| 状态 | 等待中 / 缓存中（显示进度百分比）/ 已完成 / 缓存失败 |

### 7.3 清理缓存

清理方式有三种：

| 方式 | 操作 |
| --- | --- |
| 单条删除 | 在缓存列表中向左滑动某条视频，或长按后选择删除 |
| 一键清理 | 进入「我的 → 设置 → 清理缓存」，一键清空所有缓存 |
| 自动清理 | 当缓存总量接近上限（5GB）时，APP会自动清理最早缓存的视频 |

> ⚠️ **注意**：缓存清理后无法恢复，请确认不再需要再删除。

### 7.4 断点续传

- 如果缓存中途网络断开、APP退出或您手动暂停，下次打开APP会自动从断点继续下载，不用从头开始。
- 如果断点续传等待时间过长（超过60秒），会进入「缓存失败」状态，您可以点击「重试」重新下载。

> 💡 **小贴士**：缓存完成的视频在「我的 → 离线缓存」里可以直接点击播放，无需联网。

## 九、常见问题解答（FAQ）

### Q1：为什么视频播放卡顿？

**可能原因与解决办法**：

- 网络信号不好：切换到 WiFi，或移动到网络更好的地方。
- 画质太高：把画质调低一档（如从4K调到1080P）。
- 弹幕太多：调低弹幕透明度或开启屏蔽。
- 手机内存不足：关闭其他后台应用，或重启手机后再试。
- 缓存过多：到「设置 → 清理缓存」清理一下。

### Q2：为什么弹幕不显示？

- 检查弹幕开关是否打开（控制栏「弹幕」按钮）。
- 该视频可能暂时没有弹幕。
- 网络异常可能导致弹幕加载失败，请检查网络后刷新。

### Q3：缓存失败怎么办？

- 检查网络连接是否正常，建议切换 WiFi 重试。
- 检查手机存储空间是否充足，清理一些空间。
- 在「我的 → 离线缓存」中找到失败的任务，点击「重试」。
- 仍然失败请重启APP后再试。

### Q4：视频无法播放怎么办？

- 检查网络是否正常连接。
- 试试切换画质（如从高清切换到标清）。
- 退出播放页重新进入。
- 重启APP或重启手机。
- 如果只有某个视频无法播放，可能是该视频源异常，请通过反馈渠道联系我们。

### Q5：为什么耗电比较快？

- 视频播放本身比较耗电，长时间观看属正常现象。
- 屏幕亮度调低一些可节省电量。
- 后台运行的APP较多时会增加耗电，可关闭不用的应用。
- 建议在不用时及时退出APP。

### Q6：横屏为什么不自动切换？

- 请检查手机系统的「自动旋转」开关是否打开（通常在下拉通知栏中）。
- 部分视频只支持竖屏播放，属于正常情况。
- 也可以手动点击控制栏的「全屏」按钮进入横屏。

### Q7：播放进度会记忆吗？

- 会的。播放超过3秒后，APP会自动记住您的观看位置。
- 下次打开同一个视频，会从上次离开的位置继续播放。

### Q8：如何节省手机流量？

- 在「设置 → 播放设置」中把流量下的默认画质调低。
- 在「设置 → 缓存设置」中开启「仅WiFi缓存」。
- 刷短视频时可以保持静音，减少数据加载。
- 尽量在WiFi环境下缓存视频，离线观看。

### Q9：如何关闭通知？

- 到手机系统的「设置 → 应用管理 → 追剧 → 通知」中关闭通知。
- 关闭后不影响APP正常使用，仅不再显示后台播放通知。

### Q10：怎么退出登录？

- 进入「我的 → 设置 → 退出登录」即可退出当前账号。
