## 二、项目概述

### 2.1 产品定位

追剧 APP 是一款 **Android 原生商用级视频播放 APP**，对标主流视频平台能力，覆盖长视频点播、抖音式竖屏短视频、本地视频三大场景，面向 C 端观影用户提供沉浸式、流畅、安全的视频消费体验。

### 2.2 核心能力

| 能力域 | 核心能力 |
| --- | --- |
| 长视频播放 | HLS / DASH / MP4 / FLV 多格式兼容、倍速（0.25x~5x）、进度拖拽、记忆播放、断点续传、横竖屏切换、手势控亮度/音量/进度 |
| 短视频播放 | 抖音式上下滑动无缝切换、3 实例播放器池、预加载秒开首帧、双击点赞、静音自动播、音频焦点管理 |
| 本地视频 | 本地文件解析、FFmpeg 兼容奇葩编码、封面帧提取 |
| 弹幕系统 | DanmakuFlameMaster 渲染、时间轴精准同步、节流限流、低端机降级、屏蔽/透明度/字号自定义 |
| 离线缓存 | ExoPlayer DownloadManager 分片缓存、断点续传、自动清理、加密存储 |
| 安全防护 | AES-128-CBC 分片加密、内存解密边播边解、动态密钥、防抓包、防本地扒资源 |
| UI/UX | 沉浸式全屏、双主题（亮/暗）、200/250/300ms 动画体系、状态页全覆盖、横竖屏无重置切换 |

### 2.3 上线验收标准

- 播放无黑屏、无花屏、无卡顿、无内存泄漏、无 ANR 崩溃
- 弹幕同步精准，无错位、堆积、闪烁问题
- 加密机制有效，抓包无法获取完整视频资源，本地无明文视频文件
- 缓存断点续传正常，横竖屏、手势、倍速功能正常
- 高低端机型、主流 Android 版本适配兼容正常
- 代码完全符合项目统一编码规范，无违规代码、无冗余代码、无内存隐患
- 全局常量、主题色值统一复用，无魔法值、无散乱色值，UI 风格统一
- 所有 UI 动画轻量低耗，不卡顿、不黑屏、不干扰播放与弹幕渲染

### 4.2 MVVM 架构规范

- **严格分层**：`View → ViewModel → Repository → 底层工具/网络/本地`，禁止跨层调用
- **View 层**：只做 UI 刷新、控件绑定、用户事件分发，禁止写任何播放/网络/加密逻辑
- **ViewModel 层**：只做状态处理与业务调度，不持有 View 引用、不操作控件、不处理 UI
- **Repository 层**：统一管理网络、缓存、本地数据，是唯一数据源；View/ViewModel 禁止直接调用 OkHttp 或文件读写
- 所有异步逻辑**强制使用 Kotlin 协程 + Flow**，禁止 Handler / Thread / RxJava 混用
- 页面生命周期全部绑定 Lifecycle，播放器、弹幕、网络请求自动跟随页面销毁取消
- UI 状态全部密封类封装（Loading / Success / Error / Empty），禁止零散变量标记状态

### 4.3 协程 + Flow 异步模型

- 播放进度更新统一使用 `ProgressFlow` 定时推送，禁止 `Handler` 循环轮询，减少耗电与卡顿
- 网络请求统一在 Repository 层 `suspend` 函数中调度，主线程仅 `collect` Flow
- 全局状态（播放/网络/缓存）统一 `StateFlow` 分发，避免多页面状态不同步
- 协程作用域绑定 `viewModelScope` / `lifecycleScope`，页面销毁自动取消未完成任务

### 4.4 状态管理（StateFlow + 密封类）

```kotlin
// 统一 UI 状态密封类
sealed class UiState<out T> {
    object Loading : UiState<Nothing>()
    data class Success<T>(val data: T) : UiState<T>()
    data class Error(val code: Int, val msg: String) : UiState<Nothing>()
    object Empty : UiState<Nothing>()
}

// 播放状态密封类
sealed class PlayState {
    object Playing : PlayState()
    object Paused : PlayState()
    object Buffering : PlayState()
    data class Error(val code: Int, val msg: String) : PlayState()
    object Completed : PlayState()
}
```

- 所有状态通过 `StateFlow` 暴露给 View 层，View 仅 `collect` 刷新 UI
- 禁止全局 `var` 随意修改状态，状态变更必须经 ViewModel 中转

## 五、核心模块技术方案

### 5.1 ExoPlayer 播放器模块

#### 5.1.1 单例管理

- 全局唯一 `PlayerManager`（单例）封装 ExoPlayer，禁止每页 `new` 实例
- 统一初始化、`release`、`reset` 逻辑，切换视频只切换 `MediaItem`
- 横竖屏切换、页面重建**不销毁播放器实例**，只保存/恢复播放进度与状态
- 所有监听（播放状态、缓冲、进度、错误）统一封装，禁止页面零散添加监听

#### 5.1.2 硬软解策略

- 默认开启硬件解码（MediaCodec）
- 老旧机型 / 特殊编码视频自动降级 FFmpeg 软解码
- 禁止硬编码判断机型，统一封装降级逻辑

#### 5.1.3 流媒体格式兼容

| 格式 | 用途 | 优先级 |
| --- | --- | --- |
| HLS（m3u8） | 在线视频自适应码率 | 在线首选 |
| DASH | 自适应码率备选 | 备选 |
| MP4 | 通用本地/在线 | 通用 |
| FLV | 直播/旧资源兼容 | 兼容 |

#### 5.1.4 缓存与 DownloadManager

- 使用 ExoPlayer `DownloadManager` 实现分片缓存，禁止整文件下载
- 支持断点续传，缓存目录独立隔离（`video_cache`），避免被系统清理
- 缓存逻辑全部通过 `DownloadManager` 封装，禁止自行写文件下载逻辑
- 缓存进度展示、缓存管理、缓存清理统一封装

#### 5.1.5 播放控制完整性

- 倍速播放：0.25x / 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 1.75x / 2.0x / 2.5x / 3.0x / 3.5x / 4.0x / 5.0x
- 进度拖拽、静音、循环播放、记忆播放位置（>3s 才记录进度）
- 手势调节亮度 / 音量 / 进度

#### 5.1.6 异常重试机制

- 网络波动、视频加载失败、解码异常时自动重试，最大 3 次
- 失败后展示友好错误弹窗，统一错误码，不崩溃
- 解码异常、网络异常、资源异常统一拦截

#### 5.1.7 横竖屏适配

- 全屏切换时锁定屏幕方向
- 重新适配 Surface 画布，避免画面拉伸、黑屏、进度条重置
- 切换过程**不重建播放器实例**，仅 UI 适配

#### 5.1.8 视频切换固定流程

```
reset → 设置 MediaItem → prepare → play
```

禁止随意无序调用 API。

### 5.2 短视频播放器池技术

详见第十章「短视频专属技术方案」。

### 5.3 FFmpeg 辅助模块

#### 5.3.1 定位

- 不替换 ExoPlayer 内核，仅做**辅助能力补充**
- ExoPlayer 负责常规播放，FFmpeg 负责奇葩编码兼容、视频截取、帧图片提取、短视频裁剪、视频修复

#### 5.3.2 ABI 适配

- 适配 `armeabi-v7a`、`arm64-v8a`，放弃 `x86`，减少包体积

#### 5.3.3 子线程执行

- 所有转码、解析操作放在独立 IO 协程子线程，严禁主线程执行，避免 ANR
- FFmpeg 命令统一工具类封装，禁止业务代码中拼接命令，统一参数、超时、回调模板

#### 5.3.4 资源及时释放

- 每次执行完毕**必须释放 native 资源、销毁会话**，防止 OOM 内存堆积
- 长期运行避免内存堆积

#### 5.3.5 功能清单

- 异常视频格式兼容播放（ExoPlayer 硬解失败自动降级 FFmpeg 软解）
- 视频帧截图、封面提取
- 短视频裁剪、片段截取、格式转换
- 视频截图、帧提取、裁剪功能统一返回密封状态类（成功 / 失败 / 取消）

### 5.4 弹幕 DanmakuFlameMaster 模块

#### 5.4.1 层级规范

- 弹幕 View 层级低于播放器 Surface，避免遮挡视频画面
- 同时高于底部控制栏，保证视觉层级合理
- 层级顺序（从下至上）：`Surface 视频画布 → 弹幕图层 → 加载/状态遮罩 → 播放控制栏 → 弹窗提示`

#### 5.4.2 时间轴精准同步

- 视频拖拽、倍速播放、暂停时，弹幕时间轴同步刷新
- 杜绝弹幕错位、堆积、超前播放
- 同步逻辑统一封装工具类，倍速、拖拽、跳转自动校准时间戳，禁止零散同步代码

#### 5.4.3 节流限流与低端机降级

- 限制单屏最大弹幕数量（高端机 80 条，低端机 40 条）
- 高频弹幕自动节流
- 低端机型降低弹幕渲染帧率（高端 60fps，低端 30fps）
- 低端机型性能判断统一封装，禁止硬编码机型判断

#### 5.4.4 生命周期

- 弹幕初始化、启动、暂停、销毁全部跟随播放器生命周期
- 播放暂停则弹幕暂停，页面销毁立即停止渲染
- 页面退出、视频切换**强制清空弹幕队列**，杜绝残留、错乱、内存泄漏

#### 5.4.5 交互能力

- 弹幕屏蔽、颜色切换、透明度调节、弹幕开关
- 历史弹幕预加载（提前 5s 加载后续弹幕）
- 弹幕数据解析统一预处理，过滤异常时间戳、重复数据、空数据

### 5.5 OkHttp 网络层模块

#### 5.5.1 单例与拦截器

- 全局唯一 `OkHttpClient` 单例，统一拦截器、超时、重试、请求头、日志配置
- 禁止多处 `new Client`
- 请求头统一配置、Token 携带、超时统一处理、日志打印、异常拦截

#### 5.5.2 分片下载超时

- 普通接口超时 15s
- 视频分片下载超时 30s（流媒体下载超时大于普通接口，避免大视频加载失败）
- 两套超时配置分开封装

#### 5.5.3 连接池复用

- 开启 OkHttp 连接池复用，减少频繁创建连接带来的延迟
- 最大空闲连接 5，存活时间 60s

#### 5.5.4 生命周期取消

- 所有网络请求**绑定生命周期自动取消**，页面关闭终止未完成请求
- 杜绝无用流量、后台回调空指针
- 禁止 UI 线程调用网络请求，所有网络逻辑通过 Repository 层协程调度

#### 5.5.5 网络状态监听

- 结合 Jetpack `ConnectivityManager`，无网络、弱网、WiFi/流量切换实时提示用户
- 自动暂停播放

#### 5.5.6 统一异常封装

- 无网、超时、4xx/5xx、解析失败，全局统一 Toast / 状态页处理

### 5.6 AES 加密安全模块

#### 5.6.1 加密模式

- **AES-128-CBC** 商用加密模式
- 禁止 ECB 不安全模式
- 配置固定 IV 偏移量（16 位），密钥私有化部署，禁止硬编码明文密钥
- 加密分片对齐大小：16 字节（AES 强制对齐）

#### 5.6.2 双重加密

- **传输加密 + 本地缓存文件加密**
- 网络传输视频分片加密
- 本地缓存视频文件二次加密存储，防止本地扒资源

#### 5.6.3 分片加密与边解边播

- 视频不整体加密，采用分片加密、边解密边播放
- 无需完整解密文件，提升播放速度与安全性
- 视频分片解密必须**内存解密、边解边播**，禁止落地明文文件，杜绝资源泄露
- 短视频分片 AES 加密适配小文件快速加解密，不影响秒开速度

#### 5.6.4 动态密钥

- APP 启动后从服务端拉取临时密钥
- 密钥定时过期更新（24 小时自动更新）
- 杜绝固定密钥被破解

#### 5.6.5 解密异常处理

- 解密失败统一捕获异常，自动重试、终止播放、提示资源失效，禁止崩溃
- 所有加解密操作放在子线程，禁止主线程加解密造成卡顿

#### 5.6.6 接口数据安全

- 接口数据加密、请求签名、防篡改处理

## 六、代码规范

### 6.1 Kotlin 通用规范

- 全部使用**纯 Kotlin 开发**，禁止混合大量 Java 代码，仅 Native/so 底层兼容代码可保留 Java
- 严格遵循 Google Kotlin 官方编码规范
  - 类名：大驼峰（`PlayerManager`）
  - 变量 / 函数：小驼峰（`playVideo`）
  - 常量：全大写下划线分隔（`MAX_RETRY_COUNT`）
- 杜绝魔法值：播放时长、缓存阈值、重试次数、弹幕数量、超时时间、加密参数全部定义 `const val` 常量
- 强制空安全：所有可空变量严格使用 `?` 与 `!!`；`lateinit` 仅用于注入控件，禁止用于播放器实例
- 函数单一职责：一个函数只做一件事，禁止超长函数（超过 80 行必须拆分）
- 禁止全局无控制变量：播放器状态、缓存状态、弹幕状态统一通过 `StateFlow` 托管
- 代码注释规范：核心代码（播放器逻辑、加解密逻辑、FFmpeg 命令、弹幕同步逻辑）必须写功能注释

### 6.2 MVVM & Jetpack 规范

- 严格分层：`View → ViewModel → Repository → 底层工具/网络/本地`，禁止跨层调用
- View 层：禁止写任何播放逻辑、网络逻辑、加密逻辑
- ViewModel 层：不持有 View 引用、不操作控件、不处理 UI
- Repository 层：统一管理网络、缓存、本地数据，是唯一数据源
- 异步逻辑强制使用 Kotlin 协程 + Flow，禁止 Handler / Thread / RxJava
- 生命周期全部绑定 Lifecycle
- UI 状态全部密封类封装（Loading / Success / Error / Empty）

### 6.3 ExoPlayer 专属规范

- 全局单例 `PlayerManager`，统一初始化 / release / reset
- 监听统一封装，禁止页面零散添加监听
- 进度更新统一 `ProgressFlow`，禁止 Handler 循环轮询
- 视频切换固定流程：`reset → 设置 MediaItem → prepare → play`
- 异常统一拦截，统一错误码、重试、弹窗提示
- 缓存全部通过 `DownloadManager`，禁止自行写文件下载
- 横竖屏切换、页面重建不销毁播放器实例

### 6.4 FFmpeg 规范

- 所有执行逻辑放在 IO 协程子线程，严禁主线程
- 命令统一工具类封装，禁止业务代码拼接命令
- 每次执行完毕必须释放 native 资源、销毁会话
- 异常视频兼容做降级封装：优先硬解，失败自动 FFmpeg 软解，禁止硬编码判断机型
- 截图、帧提取、裁剪统一返回密封状态类

### 6.5 弹幕规范

- 初始化、启动、暂停、销毁跟随播放器生命周期
- 时间轴同步逻辑统一工具类封装，禁止零散同步代码
- 数据解析统一预处理，过滤异常时间戳、重复数据、空数据
- 低端机型性能判断统一封装，自动降低帧率、限制最大条数
- 页面退出、视频切换强制清空弹幕队列

### 6.6 OkHttp 规范

- 全局唯一 `OkHttpClient` 单例
- 普通接口超时与视频分片下载超时两套配置分开封装
- 网络请求统一封装在 Repository，Activity/Fragment 禁止直接发起
- 所有请求绑定生命周期自动取消
- 统一网络异常封装：无网、超时、4xx/5xx、解析失败

### 6.7 AES 加密规范

- 加解密逻辑全部封装独立工具类
- 禁止密钥、IV 硬编码明文，必须 Native 加密存储或服务端动态下发
- 严格使用 AES-128-CBC，禁止 ECB，参数统一全局常量配置
- 视频分片解密必须内存解密、边解边播，禁止落地明文文件
- 解密失败统一捕获异常，自动重试、终止播放、提示资源失效
- 所有加解密操作放在子线程

### 6.8 UI 布局规范

- 全局使用 ViewBinding，禁止 findViewById
- 布局层级尽量扁平化，播放器页面布局嵌套不超过 3 层
- 所有尺寸使用 dp / sp，禁止 px
- 播放器、弹幕、控制栏层级固定写死，禁止动态修改 Z 轴
- 控件点击事件统一 lambda 规范，禁止匿名内部类

### 6.9 性能与内存规范

- 所有资源（播放器、弹幕线程、FFmpeg 会话、网络请求、定时器）必须成对释放，谁创建谁销毁
- 禁止静态持有 Activity / Fragment / View 实例
- 循环播放、弹幕滚动、进度刷新等高频逻辑严格控制帧率与执行频率
- 大文件、视频字节流、Bitmap 资源使用完毕立即回收
- 所有日志上线前统一控制开关，禁止线上打印密钥、视频地址、用户隐私信息

## 九、UI 动画方案

### 9.1 核心设计原则

- **轻动画、低耗时**：全部动画时长 200ms~300ms，禁止长耗时动画抢占播放器渲染线程
- **不干扰播放内核**：播放器画布、弹幕图层禁止叠加位移/缩放动画，仅上层控件做动画
- **低端机型自动降级**：低端机关闭复杂渐变、帧动画，仅保留基础透明渐变动画，保证 60 帧流畅
- **状态联动动画**：动画与播放状态、控件显示状态绑定，无无效动画、无残留动画

### 9.2 控制栏显隐动画

- 动画类型：透明度渐变 + 垂直位移回弹
- 显示动画：控制栏从底部外位移 20dp → 归位，透明度 0→1，时长 **250ms**
- 隐藏动画：控制栏原位 → 底部外位移 20dp，透明度 1→0，时长 **200ms**
- 适配规则：暂停状态禁止隐藏动画，常驻显示；播放无操作自动触发隐藏动画
- 避坑点：动画过程禁止刷新播放器画布，避免画面闪烁

### 9.3 手势反馈动画

- 动画类型：透明度渐变 + 缩放微动
- 出现动画：浮窗中心缩放 0.9f→1.0f，透明度 0→1，时长 **200ms**
- 消失动画：透明度 1→0，时长 **300ms**，无突兀消失
- 适配场景：左右滑进度、左侧亮度、右侧音量调节全局生效

### 9.4 播放按钮动画

- 动画类型：属性形变动画 + 按压缩放
- 点击按压动画：按钮 1.0f→0.95f→1.0f，轻微回弹，提升点击质感
- 状态切换动画：播放/暂停图标平滑切换，透明度过渡，无瞬间闪变
- 居中暂停按钮：视频暂停时居中播放按钮淡入，播放时淡出

### 9.5 加载/缓冲动画

- 动画类型：环形匀速旋转动画 + 透明度呼吸动画
- 缓冲 Loading：环形旋转，匀速 360° 循环，无卡顿、无抖动
- 弱网缓冲提示：文字"缓冲中..."搭配慢速呼吸渐变动画
- 适配规则：播放正常后立即停止动画，释放 CPU 资源

### 9.6 横竖屏切换动画

- 动画类型：全局画布平滑缩放过渡
- 动画逻辑：切换瞬间画面轻微缩放适配屏幕，控件同步渐变显隐
- 避坑重点：动画全程**不重建播放器实例**，仅 UI 适配，无进度丢失、无黑屏

### 9.7 弹幕设置弹窗动画

- 动画类型：底部弹出平移动画 + 背景变暗渐变
- 弹出：从屏幕底部向上平移入场，透明度 0→1，时长 **250ms**
- 收起：向下平移退场，透明度 1→0，时长 **200ms**
- 背景动画：弹窗显示时背景黑色透明度从 0→0.6 渐变，聚焦弹窗操作

### 9.8 视频切换动画（上一集/下一集）

- 动画类型：画面淡入淡出过渡
- 切换逻辑：旧视频画面透明度 1→0，新视频画面 0→1，交叉渐变
- 优势：配合 ExoPlayer 预加载，实现无缝切换观感

### 9.9 缓存进度动画

- 动画类型：属性值平滑更新动画
- 逻辑：缓存进度不瞬间跳变，匀速平滑填充进度条，观感更流畅
- 适配场景：视频分片下载、离线缓存列表进度展示

### 9.10 禁止使用的动画

- 禁止对 TextureView / SurfaceView 播放器画布做缩放、位移、旋转动画（极易黑屏、闪烁、解码异常）
- 禁止帧动画、GIF 动画高频循环播放（高耗电、占用播放线程资源）
- 禁止超长动画（时长 > 500ms）、弹簧抖动动画（破坏沉浸式极简风格）
- 禁止弹幕图层叠加动画（会导致弹幕错位、渲染卡顿）

### 9.11 动画全局统一常量

| 常量名 | 值 | 用途 |
| --- | --- | --- |
| 动画快速时长 | 200 ms | 退场、点击反馈 |
| 动画标准时长 | 250 ms | 弹窗、控件显隐 |
| 动画慢速时长 | 300 ms | 渐变退场、呼吸动画 |
| 动画插值器 | 默认匀速 / 轻微减速 | 无突兀回弹 |

## 十、短视频专属技术方案

本章针对**抖音/快手同款竖屏短视频沉浸式播放**场景，补齐短视频滑动、预加载、无缝衔接、极致流畅、低延迟核心能力，完全适配现有技术栈（Kotlin + ExoPlayer + Jetpack）。

### 10.1 短视频与长视频核心技术差异

| 维度 | 长视频 | 短视频 |
| --- | --- | --- |
| 核心目标 | 缓存、进度记忆、倍速、横竖屏、断点续传 | 秒开、预加载、上下滑动无缝切换、零卡顿、预渲染、静音自动播放 |
| 进度记忆 | 强需求 | 弱化 |
| 切换速度 | 不追求极速切换 | 必须无缝、零黑屏、首帧 ≤100ms |
| 内存管理 | 单实例复用 | 多实例池，严控内存暴涨 |
| 播放形态 | 横竖屏可切 | 强制竖屏 9:16、沉浸式全屏独占 |

短视频核心痛点：滑动掉帧、切换黑屏、首帧慢、连续播放内存暴涨、手势冲突、声音切换突兀。

### 10.2 多实例播放器池技术

- **3 个播放器缓存池**：当前播放 + 上一个预存 + 下一个预加载
- 实现上下滑动**零黑屏、无缝衔接**（抖音核心底层方案）
- 短视频专属播放策略：静音预加载、自动播放、页面可见性联动播放/暂停
- 智能释放策略：滑动离开后延迟回收播放器，快速回滑无需重新加载
- 短视频循环播放：单视频无限循环，贴合短视频产品形态
- 首帧极速渲染：关闭多余解码校验，开启 ExoPlayer 极速渲染模式，首帧渲染 ≤100ms

### 10.3 ViewPager2 列表滑动容器

- 使用 `ViewPager2` / RecyclerView Pager 实现标准上下一页全屏滑动效果
- 禁用横向滑动，匹配抖音交互
- 页面精准监听：`OnPageChangeCallback` 精准区分滑动状态（拖拽、滑动中、滑动完成）
- 滑动节流防抖：防止快速连滑导致多次预加载、播放器实例错乱、内存峰值暴涨
- 全屏独占布局：每个 Item 铺满屏幕，无留白、无适配拉伸，强制竖屏 9:16 比例

### 10.4 智能预加载技术

- 可视区域预加载：当前播放、预加载下 1 个、缓存上 1 个，始终保持 3 个就绪视频
- 弱网/流量智能降级：WiFi 下全额预加载；流量下仅预加载首帧、降低码率，节省流量
- 预加载时机优化：页面静止、无滑动操作时触发预加载，滑动中暂停多余预加载，避免抢占资源卡顿
- 预加载缓存阈值：短视频单文件预加载缓冲 2000ms 即可就绪，无需长视频大缓冲

### 10.5 沉浸式全屏与系统适配

- 极致沉浸式：隐藏状态栏、导航栏，适配刘海屏、挖孔屏、水滴屏、折叠屏全屏显示
- 固定竖屏锁定：短视频页面强制竖屏，禁止横竖屏旋转
- 屏幕常亮：播放短视频时自动保持屏幕常亮，暂停/退出页面关闭常亮
- 系统窗口适配：规避系统手势、状态栏遮挡视频画面

### 10.6 音频焦点管理

- 系统音频焦点监听：切后台、其他 APP 播放音频时自动暂停视频、静音
- 滑动切换音频平滑启停：上一个视频静音淡出、下一个视频有声淡入，无爆音、无突兀切换
- 全局静音/有声状态记忆：跟随用户设置，统一所有短视频播放状态

### 10.7 短视频专属缓存策略

- 短时缓存机制：短视频不需要永久缓存，采用**临时内存缓存 + 短时磁盘缓存**
- 智能淘汰策略：自动淘汰 30 分钟未访问、滑动划过的视频缓存，严控包体积与内存
- 分片极速加载：适配短视频 HLS/TS 分片，小文件快速加载，秒开率拉满

### 10.8 手势交互增强

- 双击点赞手势：精准双击识别，防误触，搭配点赞缩放动画
- 左右滑动交互：左侧评论、右侧个人主页弹窗滑出，与上下滑动播放不冲突
- 单击启停播放：单击视频暂停/继续播放，隐藏/显示操作 UI
- 手势优先级分级：上下滑动翻页 > 单击播放 > 双击点赞 > 左右侧滑弹窗

### 10.9 低性能机型降级

- 低端机关闭三播放器池，改为单实例复用，降低内存占用
- 降级预加载数量：仅预加载下 1 个视频，减少 CPU/网络消耗
- 降低解码帧率：锁定 30 帧播放，杜绝低端机掉帧卡顿
- 关闭多余动画、点赞特效、弹幕高频渲染，保证基础流畅度

### 10.10 短视频配套 UI 与动画

- 全屏沉浸式 UI 结构：视频画布底层，右侧头像、关注、点赞、评论、分享悬浮层置顶
- 无缝切换动画：页面滑动无黑屏、无闪烁，画面跟随手势位移过渡
- 点赞粒子动画、爱心缩放动画、按钮按压微动动画
- 底部文案、话题标签、音乐文案滚动动画
- 弹窗侧滑动画：评论弹窗、个人主页弹窗左右平滑弹出收起

### 10.11 短视频安全与加密适配

- 短视频分片 AES 加密：适配小文件快速加解密，不影响秒开速度
- 内存解密播放：禁止短视频明文落地，防止批量爬取、盗录资源
- 链接时效限制：短视频播放链接短期过期，防止永久盗用转发

### 10.12 短视频性能避坑规范

- 禁止无限创建播放器实例，必须使用播放器对象池复用，杜绝 OOM
- 滑动过程禁止大量网络请求、解析任务，避免页面卡顿掉帧
- 短视频页面严格禁止布局嵌套冗余，保证滑动帧率稳定 60 帧
- 及时释放离屏播放器、停止解码线程，防止后台持续耗电
- 禁止短视频播放页面触发系统回收重建，锁定页面状态与播放器实例

### 10.13 短视频完整能力清单

- 上下滑动无缝切换视频、秒开播放、静音自动播
- 双击点赞、右侧功能栏（点赞/评论/收藏/分享/关注）
- 视频循环播放、音频平滑切换、静音/有声切换
- 预加载智能缓存、弱网适配、流量节省模式
- 全屏沉浸式播放、屏幕常亮、竖屏锁定
- 短视频弹幕、话题标签、背景音乐滚动展示
- 高低端机型适配、性能降级、帧率稳定
- 加密资源播放、防爬防盗、时效链接

## 十一、性能与兼容

### 11.1 分区存储

- 适配 Android 10+ 分区存储机制（`Build.VERSION_CODES.Q`）
- 视频缓存、本地视频读取严格遵循分区存储规范，避免权限报错
- 缓存目录独立隔离（`video_cache`），避免被系统清理

### 11.2 后台 Service

- 后台播放适配：开启前台 Service，适配系统后台权限限制
- 后台播放权限适配版本：Android 12.0（`Build.VERSION_CODES.S`）
- 避免后台播放被系统杀死

### 11.3 功耗优化

- 播放时自动适配屏幕常亮，暂停后关闭常亮
- 闲置状态释放播放器资源
- 高频逻辑（循环播放、弹幕滚动、进度刷新）严格控制帧率与执行频率
- 缓冲 Loading 正常播放后立即停止动画，释放 CPU 资源

### 11.4 机型适配

- 适配不同分辨率、dpi 机型，所有控件使用 dp/sp 单位，禁止 px
- 高端机开启 4K、高帧率播放
- 低端机自动降分辨率、关闭高耗能滤镜与动画
- 低端机 CPU 核心数阈值 4 核，低于阈值自动降级 UI、帧率
- 适配刘海屏、挖孔屏、折叠屏：播放画面自动避开刘海、挖孔区域
- 内存泄漏检测与修复（播放器、弹幕、网络线程）
- 卡顿优化、帧率监控、ANR 修复

### 11.5 内存规范

- 所有资源必须成对释放，谁创建谁销毁
- 禁止静态持有 Activity/Fragment/View 实例
- 大文件、视频字节流、Bitmap 资源使用完毕立即回收

## 十二、安全规范

### 12.1 密钥管理

- 密钥动态下发：APP 启动后从服务端拉取临时密钥
- 密钥定时过期更新（24 小时自动更新）
- 密钥私有化部署
- 密钥过期时间常量：`24 * 60 * 60 * 1000` ms

### 12.2 防硬编码

- 禁止密钥、IV 硬编码明文
- 必须通过 Native 加密存储或服务端动态下发
- 所有加密参数统一全局常量配置（AppConstants.kt）

### 12.3 防抓包

- 接口数据加密、请求签名、防篡改处理
- 抓包无法获取完整视频资源
- 视频分片加密传输

### 12.4 防本地扒资源

- 本地缓存视频文件二次加密存储
- 内存解密播放，禁止解密后明文落地
- 不保存明文视频文件，杜绝资源泄露
- 短视频链接时效限制，防止永久盗用转发

### 12.5 加密模式强制

- 严格使用 AES-128-CBC 模式，禁止 ECB 模式
- IV 偏移量固定 16 位向量，全局统一，禁止随意修改
- 加密分片对齐大小 16 字节（AES 强制对齐）

### 12.6 日志安全

- 所有日志上线前统一控制开关
- 禁止线上打印密钥、视频地址、用户隐私信息

### 12.7 安全自查清单

- [ ] 密钥防硬编码
- [ ] 防抓包
- [ ] 防本地扒资源
- [ ] Native 加密存储
- [ ] 服务端动态密钥
- [ ] 内存解密不落地
- [ ] 接口签名防篡改
- [ ] 短视频时效链接

## 十三、打包混淆规范

### 13.1 混淆开启

- 正式包必须开启混淆、资源压缩
- 过滤无用资源与调试代码

### 13.2 禁止混淆类

- 播放器核心类（PlayerManager 等）
- FFmpeg 核心类（FFmpegCmd 等）
- 加密核心类（AES 工具、KeyManager）
- native 方法、JNI 调用类
- 数据模型类（与序列化相关）

### 13.3 测试包 / 正式包隔离

- 区分测试包/正式包环境
- 域名、密钥、日志、调试功能隔离
- 禁止测试代码混入正式包

### 13.4 ABI 与包体积

- 主流架构：`armeabi-v7a`、`arm64-v8a`
- 放弃 `x86`、`x86_64`，减少包体积（模拟器调试除外）

### 13.5 资源压缩

- 开启资源压缩（`shrinkResources true`）
- 过滤无用资源与调试代码
