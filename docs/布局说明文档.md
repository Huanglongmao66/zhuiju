# 追剧APP 布局说明文档

## 一、文档说明

### 1.1 文档目的
本文档是追剧APP（zhuiju）项目的布局规范与开发落地指南，用于统一全工程 UI 布局选型、层级规范、尺寸常量与适配标准，保证商用级视频播放体验下的帧率稳定、无卡顿、无黑屏、无手势冲突。

### 1.2 适用范围
- 适用范围：追剧APP 全部页面布局开发与维护
- 适用人员：Android 开发、UI 评审、测试验收
- 适用技术栈：Kotlin + Jetpack + ExoPlayer + FFmpeg + DanmakuFlameMaster + OkHttp + AES
- 涉及页面：五大主页（首页 / 发现 / 排行榜 / 找片 / 我的）+ 播放页四大布局方案

### 1.3 核心原则
- 层级≤3，杜绝过度绘制
- TextureView 优先，SurfaceView 降级备用
- dp/sp 单位统一，禁止 px
- 统一常量、双主题色值，无硬编码

---

## 二、全局布局规范

### 2.1 层级规范
- 所有页面布局层级**严格≤3 层**
- 禁止多层嵌套 RelativeLayout、LinearLayout
- 播放核心区域禁止任何滚动嵌套、手势冲突布局
- 禁止 `ScrollView` 嵌套 `RecyclerView`（严重卡顿）

### 2.2 视频画布规范
- 视频画布统一使用 **TextureView 优先**
- SurfaceView 仅作为低端机型降级备用
- 视频画布 `match_parent` 铺满父布局，禁止固定尺寸
- UI 动画仅作用顶层控件，**不对视频画布、弹幕图层做动画**

### 2.3 单位规范
- 所有尺寸使用 `dp` / `sp`，禁止 `px`
- 全局适配，支持刘海屏、挖孔屏、折叠屏

### 2.4 圆角规范（全局统一）

| 用途 | 圆角值 |
| --- | --- |
| 卡片 | 12dp |
| 按钮 | 8dp |
| 标签 | 4dp |

### 2.5 间距规范（三档标准）

| 档位 | 间距值 | 用途 |
| --- | --- | --- |
| 小间距 | 10dp | 控件内部、紧密元素 |
| 中间距 | 15dp | 卡片之间、模块内部 |
| 大间距 | 20dp | 模块之间、页面边距 |

### 2.6 动画规范（三档统一）

| 档位 | 时长 | 用途 |
| --- | --- | --- |
| 快 | 200ms | 按钮、Tab 切换 |
| 中 | 250ms | 卡片显隐、状态切换 |
| 慢 | 300ms | 折叠头部、页面过渡 |

> 禁止超长动画，列表滑动流畅优先级高于复杂动画。

### 2.7 状态页规范
- 加载、空数据、错误、重试状态全局统一 UI
- 主题色、文字色、透明度全局复用 `color` 资源，无硬编码色值

### 2.8 列表与图片规范
- 所有图片封面固定比例：横屏 16:9、竖屏 9:16，禁止拉伸变形
- 所有列表开启**下拉刷新、上拉加载**统一封装
- Fragment 全部开启懒加载，不可见时不请求网络、不渲染数据

## 三、全局公共架构说明

### 3.1 整体架构
全局采用 **MainActivity + ViewPager2 + 5 大 Fragment + 底部导航栏** 架构。

### 3.2 根布局结构

```xml
<!-- MainActivity 根布局（层级 3） -->
ConstraintLayout
├─ 沉浸式状态栏占位层
├─ ViewPager2（主体内容，承载 5 个主页 Fragment，懒加载）
└─ 底部常驻导航栏（首页 / 发现 / 排行榜 / 找片 / 我的）
```

### 3.3 五大主页 Fragment 划表

| Fragment | 页面定位 | 核心布局组件 |
| --- | --- | --- |
| 首页 | 短视频 Feed 流 | 竖直 ViewPager2 + FrameLayout |
| 发现页 | 热门推荐 / 合集 | ConstraintLayout + Banner + Tab + 双列 Grid |
| 排行榜 | 热度榜单 | ConstraintLayout + TabLayout + 单列 List |
| 找片 | 搜索 + 分类 | ConstraintLayout + ScrollView + 多横向 List |
| 我的 | 个人中心 | CoordinatorLayout + 折叠头部 + Tab + ViewPager2 + 双列 Grid |

### 3.4 公共强制规范（所有页面通用）
- 非播放页根布局统一使用 **ConstraintLayout**，层级扁平、测量高效
- 视频播放页 Item 统一 **FrameLayout**，极致防卡顿
- 所有页面适配**刘海屏、挖孔屏、折叠屏、沉浸式状态栏**

## 四、五大主页布局详解

### 4.1 首页（短视频 Feed 流）

#### 4.1.1 页面定位
抖音式上下滑动全屏沉浸式短视频播放，APP 核心性能页面，优先级最高。

#### 4.1.2 布局选型
**外层：ViewPager2（竖直方向） + 内层 Item：FrameLayout 极简布局**

#### 4.1.3 层级结构

```Plain Text
ViewPager2(vertical)
└─ Item Fragment(FrameLayout)
   ├─ TextureView（视频全屏画布 9:16）
   ├─ DanmakuView（弹幕层）
   ├─ 点击播放/暂停遮罩
   ├─ 右侧悬浮功能区（头像、关注、点赞、评论、收藏、分享）
   └─ 底部文案区（标题、话题、背景音乐、作者信息）
```

#### 4.1.4 开发注意事项
- ViewPager2 必须设置 `offscreenPageLimit = 1`，配合播放器池预加载
- 页面强制锁定**竖屏**，禁止横竖屏切换
- 全屏沉浸式，隐藏状态栏、导航栏，无黑边、无留白
- Item 布局层级严格控制在 **3 层以内**，保证 60 帧滑动
- UI 控件全部悬浮，不挤压视频画布尺寸
- 单击视频暂停/播放、双击点赞手势精准识别，防误触

#### 4.1.5 核心禁忌
- 禁止任何 ScrollView、嵌套 RecyclerView，杜绝手势冲突
- 禁止嵌套复杂布局、多层 RelativeLayout
- 禁止自动旋转

---

### 4.2 发现页（热门推荐 / 合集）

#### 4.2.1 页面定位
热门视频、推荐合集、活动 Banner、种草内容，双列卡片信息流。

#### 4.2.2 布局选型
**ConstraintLayout + 顶部轮播 + 分类 Tab + 双列 Grid RecyclerView**

#### 4.2.3 层级结构

```Plain Text
ConstraintLayout
├─ 顶部 Banner 轮播（ViewPager）
├─ 横向分类 Tab 栏（可滚动）
├─ 分割线 / 标题
└─ RecyclerView（Grid 2 列）
   └─ Item：视频卡片（封面 + 播放图标 + 标题 + 热度 + 作者）
```

#### 4.2.4 开发注意事项
- 双列卡片**统一固定比例 9:16**，界面整齐统一
- 卡片添加圆角（12dp）、阴影、按压效果，提升质感
- Banner、Tab、列表分层隔离，互不冲突
- 图片预加载、占位图、错误图兜底，避免空白闪烁
- 列表滑动流畅优先级高于复杂动画，禁止卡片过多动效
- Item 点击统一跳转短视频播放页，携带视频 ID 索引

#### 4.2.5 核心禁忌
- 禁止卡片尺寸混乱、比例错乱
- 禁止卡片过多动效拖慢列表

---

### 4.3 排行榜（热度榜单）

#### 4.3.1 页面定位
日榜 / 周榜 / 月榜视频热度排名，有序榜单展示，结构规整、信息层级清晰。

#### 4.3.2 布局选型
**ConstraintLayout + 顶部 TabLayout + 单列 RecyclerView**

#### 4.3.3 层级结构

```Plain Text
ConstraintLayout
├─ 顶部 Tab（日榜 / 周榜 / 月榜）
├─ 榜单标题、更新时间
└─ 单列 RecyclerView
   └─ Item：横向布局（排名 + 头像 + 昵称 + 封面 + 热度 + 关注按钮）
```

#### 4.3.4 开发注意事项
- 前三名特殊样式：金牌 / 银牌 / 铜牌图标替代数字排名
- 列表 Item 高度统一，避免参差不齐
- Tab 切换快速刷新数据源，禁止重复请求、禁止页面重建
- 榜单数据缓存本地，二次进入快速展示、再刷新
- 排名数值、热度文案醒目突出，信息层级清晰
- 支持下拉刷新榜单、上拉加载更多尾部数据

#### 4.3.5 核心禁忌
- 禁止 Item 高度混乱、排版杂乱
- 禁止 Tab 切换重建页面

---

### 4.4 找片（搜索 + 分类）

#### 4.4.1 页面定位
全站搜索、热门搜索、全品类分类、分区视频推荐，内容最多、模块最多。

#### 4.4.2 布局选型
**ConstraintLayout + 竖向 ScrollView + 多组横向 RecyclerView**

#### 4.4.3 层级结构

```Plain Text
ConstraintLayout
├─ 顶部搜索框（搜索、清空、历史搜索）
├─ 热门搜索标签流式布局
├─ 全部分类横向列表（游戏 / 生活 / 美食 / 影视等）
├─ 分区 1：标题 + 横向视频卡片列表
├─ 分区 2：标题 + 横向视频卡片列表
└─ 分区 3：标题 + 横向视频卡片列表
```

#### 4.4.4 开发注意事项
- **严禁竖向 RecyclerView 嵌套横向 RecyclerView**，采用 ScrollView 承载所有分区
- 所有横向列表开启复用、预加载，流畅滑动
- 搜索状态与浏览状态 UI 自动切换：搜索后隐藏所有分类，只展示结果列表
- 热门搜索、历史搜索独立缓存，本地持久化
- 分类选中状态高亮、主色标记，视觉反馈明确
- 分区模块懒加载，滑动到可视区域再加载数据，减少启动卡顿

#### 4.4.5 核心禁忌
- 禁止列表嵌套列表（RecyclerView 嵌套 RecyclerView）
- 禁止一次性加载所有分区数据导致启动卡顿

---

### 4.5 我的（个人中心）

#### 4.5.1 页面定位
用户资料、粉丝数据、作品 / 收藏 / 喜欢 / 私密作品列表，个人中心核心页。

#### 4.5.2 布局选型
**CoordinatorLayout + CollapsingToolbar 折叠头部 + TabLayout + ViewPager2 + 双列 Grid 列表**

#### 4.5.3 层级结构

```Plain Text
CoordinatorLayout
├─ 折叠头部（背景大图 + 头像 + 昵称 + 简介 + 数据统计）
├─ Tab 栏（作品 / 私密 / 收藏 / 喜欢）
└─ ViewPager2
   └─ 子 Fragment：双列 Grid RecyclerView（视频作品卡片）
```

#### 4.5.4 开发注意事项
- 折叠头部滑动联动：上滑收缩、下拉展开，动效流畅不卡顿
- 用户数据（获赞、关注、粉丝）UI 排版整齐，数值醒目
- Tab 与 ViewPager2 双向联动，滑动、点击同步
- 作品列表统一 9:16 双列卡片，和发现页视觉统一
- 无作品、无收藏、无数据时展示空状态页面
- 头像、背景图支持圆角、模糊、适配沉浸式
- 设置、夜间模式、帮助中心等功能入口统一排布底部

#### 4.5.5 核心禁忌
- 禁止头部卡顿、Tab 联动失效
- 禁止折叠动效过长（≤300ms）

## 五、播放页四大布局方案详解

### 5.1 方案一：长视频 FrameLayout（主推）

#### 5.1.1 适用场景
剧集、电影、网课、长视频点播页面（支持横竖屏切换、手势控亮度音量、弹幕、控制栏显隐）。

#### 5.1.2 布局结构

```xml
<!-- 层级 2 层，极简不卡顿 -->
FrameLayout（根布局）
├─ TextureView（视频渲染画布，铺满父布局）
├─ DanmakuView（弹幕图层，匹配视频尺寸）
└─ 播放器 UI 容器（控制栏、进度条、加载状态、手势浮窗）
```

#### 5.1.3 层级顺序（从下至上）
```
TextureView 视频画布 → 弹幕 View → 状态遮罩层 → 底部 / 顶部控制栏 → 弹窗提示
```

#### 5.1.4 核心优势
- FrameLayout 无测量嵌套，**全程 60 帧稳定**，无掉帧、无过度绘制
- TextureView 优先渲染，支持 UI 动画、层级叠加，杜绝 SurfaceView 黑屏闪烁问题
- 弹幕与视频精准对齐，倍速 / 拖拽不同步问题最少
- 横竖屏切换布局重建量最小，播放进度不丢失、UI 不乱窜
- 完美兼容手势识别（亮度 / 音量 / 进度），无触控冲突

#### 5.1.5 强制规范与避坑
- 所有控件宽高统一 `match_parent` 铺满，禁止固定尺寸
- 控制栏、进度条使用 **match_parent + 底部 / 顶部对齐**，不挤压视频画布
- 加载动画、错误状态页统一覆盖全屏，不改变视频画布尺寸
- 根布局禁止嵌套 ScrollView、RecyclerView，防止触控冲突、画面偏移

---

### 5.2 方案二：短视频 ViewPager2 + FrameLayout（主推）

#### 5.2.1 适用场景
短视频上下滑动 Feed 流、沉浸式全屏播放、点赞评论右侧悬浮 UI。

#### 5.2.2 布局结构

```xml
<!-- 整体结构 -->
ViewPager2（外层滑动容器）
└─ Item 帧布局（单条短视频页面）
   FrameLayout（单层根布局）
   ├─ TextureView（9:16 全屏铺满）
   ├─ DanmakuView（弹幕层，可选）
   └─ 沉浸式悬浮 UI 层（右侧功能栏 + 底部文案 + 音乐图标）
```

#### 5.2.3 层级顺序（从下至上）
```
TextureView 9:16 全屏画布 → 弹幕 View → 右侧悬浮功能栏 + 底部文案 + 音乐图标
```

#### 5.2.4 核心优势
- ViewPager2 原生滑动手感最接近抖音，防卡顿、防错位
- Item 极简 FrameLayout，**层级只有 2 层**，滑动帧率极致稳定
- 右侧点赞、评论、关注控件固定悬浮，不遮挡核心观影区域
- 适配播放器池三实例复用，无缝切换无黑屏
- 强制 9:16 比例，无拉伸、无留白、无黑边

#### 5.2.5 强制规范与避坑
- ViewPager2 设置 `offscreenPageLimit = 1`，配合预加载策略
- 禁止 Item 内部嵌套复杂布局、RecyclerView、多层 RelativeLayout
- 所有悬浮 UI 使用 `wrap_content` + 边距控制，不挤压视频画面
- 页面强制竖屏锁定，禁止自动旋转

---

### 5.3 方案三：兼容万能 ConstraintLayout

#### 5.3.1 适用场景
需要兼容奇葩分辨率视频、需要固定比例、低端机型适配、本地视频混合播放页面。

#### 5.3.2 布局结构

```xml
<!-- 根布局 -->
ConstraintLayout（根布局）
├─ TextureView（通过 layout_dimensionRatio 锁定视频比例）
├─ DanmakuView（弹幕层）
└─ 控制栏 / 状态遮罩（约束绑定四边）
```

#### 5.3.3 层级顺序（从下至上）
```
TextureView（比例约束锁定）→ 弹幕 View → 状态遮罩 → 控制栏 → 弹窗
```

#### 5.3.4 核心优势
- 核心通过比例约束 `layout_dimensionRatio` 锁定视频比例
- 支持动态切换 16:9 / 4:3 / 全屏 / 原始比例
- 所有 UI 控件通过约束绑定四边，适配刘海屏、挖孔屏
- 比例可控，杜绝视频拉伸变形、裁剪异常
- 适配性最强，新旧机型、异形屏全部兼容
- 适合需要**手动切换画面显示比例**的功能页面

#### 5.3.5 强制规范与避坑
- ConstraintLayout 测量耗时略高于 FrameLayout，**短视频 Feed 流禁止使用**，仅长视频使用
- 禁止过多约束链，保持布局简洁，避免测量卡顿

---

### 5.4 方案四：小窗悬浮 FrameLayout（PiP 画中画专用）

#### 5.4.1 适用场景
后台小窗播放、悬浮画中画、边刷列表边播放。

#### 5.4.2 布局结构

```xml
<!-- 浮动窗口布局 -->
FrameLayout（浮动窗口）
├─ TextureView（固定 16:9 小窗画布）
├─ 关闭按钮
└─ 放大按钮
```

#### 5.4.3 层级顺序（从下至上）
```
TextureView 小窗画布 → 关闭按钮 → 放大按钮
```

#### 5.4.4 核心优势
- 固定小窗比例 16:9，固定最小宽高
- 仅保留视频画布 + 关闭按钮 + 放大按钮
- 隐藏所有复杂控制栏、弹幕、进度 UI
- 极致轻量化、低耗电、无卡顿

#### 5.4.5 强制规范与避坑
- 小窗模式强制降低渲染帧率，节省耗电
- 禁止任何动画、弹幕渲染，极致轻量化
- 支持手势拖动悬浮窗位置

---

## 六、布局选型对照表

### 6.1 五大主页选型对照

| 页面 | 核心布局组件 | 布局特点 | 核心禁忌 |
| --- | --- | --- | --- |
| 首页 | 竖直 ViewPager2 + FrameLayout | 极简层级、全屏沉浸式、60 帧流畅 | 禁止嵌套、禁止复杂测量 |
| 发现页 | ConstraintLayout + 双列 Grid | 卡片信息流、视觉饱满 | 禁止卡片尺寸混乱、比例错乱 |
| 排行榜 | ConstraintLayout + 单列 List | 结构规整、排名清晰 | 禁止 Item 高度混乱、排版杂乱 |
| 找片 | ScrollView + 多横向 List | 多模块聚合、搜索分类一体 | 禁止列表嵌套列表 |
| 我的 | Coordinator 折叠头部 + Grid | 动态折叠、多 Tab 内容切换 | 禁止头部卡顿、Tab 联动失效 |

### 6.2 播放页四大方案选型对照

| 页面场景 | 推荐布局 | 核心理由 | 核心禁忌 |
| --- | --- | --- | --- |
| 长视频播放页（电影 / 剧集） | 方案一 FrameLayout | 帧率最高、层级最简、横竖屏最稳 | 禁止嵌套 ScrollView/RecyclerView |
| 抖音短视频 Feed 流 | 方案二 ViewPager2 + FrameLayout | 滑动丝滑、无缝切换、适配播放器池 | 禁止 Item 嵌套复杂布局、禁止横屏 |
| 多比例兼容播放页 | 方案三 ConstraintLayout | 比例可控、异形屏适配完美 | 禁止用于短视频 Feed 流、禁止过多约束链 |
| 悬浮小窗播放 | 方案四 极简 FrameLayout | 轻量化、低耗电、无卡顿 | 禁止动画、弹幕渲染 |

## 七、UI 层级规范

### 7.1 播放器层级（从下至上严格顺序）

```Plain Text
1. TextureView（视频渲染画布，最底层）
2. DanmakuView（弹幕图层，匹配视频尺寸）
3. 状态遮罩层（加载、错误、黑屏遮罩）
4. 控制栏（顶部返回 / 标题、底部进度条 / 播放暂停 / 全屏）
5. 弹窗提示（手势浮窗、亮度音量提示，最顶层）
```

### 7.2 层级硬性规则
- 视频画布永远在最底层，禁止任何控件遮挡在视频之下
- 弹幕图层位于视频之上、控制栏之下，禁止弹幕遮挡控制栏交互
- 状态遮罩层覆盖全屏，不改变视频画布尺寸
- 控制栏使用 `match_parent + 底部 / 顶部对齐`，不挤压视频画布
- 弹窗提示位于最顶层，保证手势浮窗、亮度音量提示可见
- UI 动画仅作用顶层控件，**不对视频画布、弹幕图层做动画**

### 7.3 通用层级约束
- 所有页面布局层级 **严格≤3 层**
- 播放核心区域禁止任何滚动嵌套、手势冲突布局
- 控件宽高统一 `match_parent` 铺满，禁止固定尺寸

## 九、适配规范

### 9.1 异形屏适配
- **刘海屏**：所有 UI 控件通过约束绑定四边，避开刘海区域；播放页全屏沉浸式时状态栏占位层正确占位
- **挖孔屏**：同刘海屏处理，关键交互控件避开挖孔区域
- **折叠屏**：ConstraintLayout 扁平布局天然适配折叠屏展开 / 收起，列表自动重排

### 9.2 沉浸式状态栏
- 全局根布局顶部预留沉浸式状态栏占位层
- 首页短视频 Feed 流全屏沉浸式，隐藏状态栏、导航栏
- 播放页支持横竖屏切换时状态栏显隐联动

### 9.3 横竖屏适配

| 页面 | 横竖屏策略 |
| --- | --- |
| 首页（短视频 Feed 流） | 强制竖屏锁定，禁止自动旋转 |
| 长视频播放页（方案一） | 支持横竖屏切换，布局重建量最小，进度不丢失 |
| 短视频播放页（方案二） | 强制竖屏锁定 |
| 兼容播放页（方案三） | 支持横竖屏切换，比例约束自适应 |
| 小窗播放（方案四） | 跟随宿主页面方向，固定 16:9 比例 |
| 五大主页 | 跟随系统方向，ConstraintLayout 自适应 |

### 9.4 单位适配
- 全部使用 `dp` / `sp`，禁止 `px`
- 全局适配不同屏幕密度，无硬编码尺寸

### 9.5 列表适配
- 所有列表开启下拉刷新、上拉加载统一封装
- Fragment 全部开启懒加载，不可见时不请求网络、不渲染数据
- 分区模块懒加载，滑动到可视区域再加载数据

### 9.6 状态页适配
- 加载、空数据、错误、重试状态全局统一 UI
- 无作品、无收藏、无数据时展示空状态页面
- 图片预加载、占位图、错误图兜底，避免空白闪烁

## 附录：全局布局统一强制规则

- 所有播放页面布局层级**严格≤3 层**，杜绝过度绘制
- 视频画布统一使用 **TextureView 优先**，SurfaceView 降级备用
- 所有尺寸使用 dp/sp，禁止 px，全局适配
- 播放核心区域禁止任何滚动嵌套、手势冲突布局
- UI 动画仅作用顶层控件，**不对视频画布、弹幕图层做动画**
- 非播放页根布局统一 **ConstraintLayout**
- 播放页 Item 统一 **FrameLayout**
- 全局圆角 12dp / 8dp / 4dp，间距 10 / 15 / 20dp，动画 200 / 250 / 300ms
- 主题色、文字色、透明度全局复用 color 资源，无硬编码色值
