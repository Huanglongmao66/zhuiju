## 一、软件概述

### 1.1 产品定位

追剧APP（zhuiju）是一款 **Android 原生商用级视频播放应用**，对标主流长视频点播平台与抖音式短视频产品形态，覆盖长视频点播、抖音式短视频 Feed 流、本地视频播放三大业务场景，提供弹幕、倍速、离线缓存、手势控制、横竖屏切换、AES-128-CBC 加密安全等完整商用能力。

### 1.2 核心能力

| 能力域 | 核心能力说明 |
| --- | --- |
| 长视频点播 | HLS / DASH / MP4 / FLV 主流格式自适应播放，硬解优先、软解兜底，倍速、记忆播放、断点续传 |
| 短视频 Feed 流 | 抖音式竖屏上下滑动、3 实例播放器池、秒开首帧、静音自动播放、双击点赞、预加载与智能淘汰 |
| 本地视频播放 | 兼容本地 MP4 / FLV / TS 等格式，支持分区存储读取 |
| 弹幕系统 | DanmakuFlameMaster 渲染、时间轴精准同步、屏蔽 / 颜色 / 透明度 / 字号自定义、低性能降级 |
| 离线缓存 | ExoPlayer DownloadManager 分片缓存、断点续传、加密存储、自动清理阈值 |
| 加密安全 | AES-128-CBC 分片加密、传输 + 缓存双重加密、密钥服务端动态下发、内存解密不落地 |
| 手势控制 | 左侧亮度 / 右侧音量 / 横向进度三类手势，搭配实时浮窗提示 |
| 横竖屏适配 | 横竖屏无感切换、进度与状态保持、刘海屏 / 挖孔屏 / 折叠屏适配 |
| 性能优化 | 单例播放器复用、协程 + Flow 异步、StateFlow 状态分发、高低端机型自适应降级 |

### 1.3 适用人群

- **开发工程师**：依据本说明了解功能边界、运行流程与调试入口，快速进入开发与联调。
- **测试工程师**：依据模块说明执行功能验证、兼容性测试、性能与异常场景测试。
- **运维 / 上线人员**：依据构建与打包流程产出 debug / release 包，验证环境配置与签名。

### 1.4 五大主页与播放页概览

| 页面 | 定位 | 核心布局 |
| --- | --- | --- |
| 首页 | 短视频 Feed 流上下滑动，APP 核心性能页 | 竖直 ViewPager2 + FrameLayout，沉浸式全屏 |
| 发现页 | 热门推荐、活动 Banner、双列卡片信息流 | ConstraintLayout + 顶部轮播 + Tab + 双列 Grid |
| 排行榜 | 日榜 / 周榜 / 月榜热度排名 | ConstraintLayout + TabLayout + 单列 RecyclerView |
| 找片 | 全站搜索、热门搜索、分类、分区推荐 | ConstraintLayout + ScrollView + 多组横向 List |
| 我的 | 个人资料、作品 / 收藏 / 喜欢 / 私密 | CoordinatorLayout 折叠头部 + Tab + ViewPager2 + 双列 Grid |
| 播放页 | 长视频播放核心页 | FrameLayout（TextureView → 弹幕 → 状态遮罩 → 控制栏 → 弹窗） |

## 二、运行环境要求

### 2.1 系统与机型要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Android 7.0（API 24）及以上，推荐 Android 10.0 及以上获得完整体验 |
| 最低编译版本（minSdk） | 24 |
| 目标编译版本（targetSdk） | 34（Android 14） |
| ABI 架构 | `armeabi-v7a`、`arm64-v8a`（默认打包）；放弃已废弃的 x86 架构以减小包体积 |
| 屏幕适配 | 支持刘海屏、挖孔屏、水滴屏、折叠屏；支持横竖屏；短视频页强制竖屏锁定 |
| 内存建议 | 设备 RAM ≥ 3GB；播放短视频 Feed 流建议 ≥ 4GB |
| 存储 | 安装包预留 ≥ 200MB；缓存目录预留 ≥ 5GB（受最大缓存 5GB 上限制约） |

### 2.2 网络环境要求

- 支持 WiFi / 4G / 5G 网络，弱网下自动降级预加载策略。
- 在线视频默认走 HLS 自适应码率；分片下载超时 30s，普通接口超时 15s。
- 无网络 / 弱网场景自动暂停播放并提示用户，恢复网络后支持手动重试。

### 2.3 权限说明

APP 运行所需权限及其用途如下表：

| 权限 | 类型 | 用途说明 |
| --- | --- | --- |
| `INTERNET` | 普通 | 在线视频流播放、接口请求、弹幕拉取 |
| `ACCESS_NETWORK_STATE` | 普通 | 监听网络状态，弱网 / 切网时自动暂停 |
| `ACCESS_WIFI_STATE` | 普通 | 区分 WiFi / 流量，启用差异化预加载策略 |
| `READ_EXTERNAL_STORAGE`（API ≤ 28） | 运行时 | 读取本地视频文件 |
| `WRITE_EXTERNAL_STORAGE`（API ≤ 28） | 运行时 | 缓存写入（Android 10+ 走分区存储，不再需要） |
| `READ_MEDIA_VIDEO`（API 33+） | 运行时 | 读取本地视频（Android 13 分区存储细化） |
| `FOREGROUND_SERVICE` | 普通 | 后台播放保活前台 Service |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK`（API 34+） | 普通 | 后台媒体播放前台服务类型 |
| `POST_NOTIFICATIONS`（API 33+） | 运行时 | 后台播放通知栏提示 |
| `SYSTEM_ALERT_WINDOW` | 运行时 | 悬浮小窗播放（画中画 PiP） |
| `WAKE_LOCK` | 普通 | 播放时保持屏幕常亮 |
| `VIBRATE` | 普通 | 操作反馈轻震动 |

> 权限申请遵循「按需申请 + 友好文案」原则：存储、后台播放、悬浮窗权限在用户首次触达对应功能时申请，弹窗说明用途，无强制阻断。

### 3.3 so 库集成说明

- **FFmpeg so 库**：默认通过 `ffmpeg-kit` 三方依赖引入，自动支持 `armeabi-v7a` / `arm64-v8a`。如需自行编译，请将 `libffmpeg.so` 放至 `src/main/jniLibs/<abi>/`，并在 `CMakeLists.txt` 中配置链接。
- **ExoPlayer native 库**：随 `androidx.media3` 依赖自动引入，无需手动管理。
- **DanmakuFlameMaster native 库**：纯 Java/Kotlin 实现，无 so 库依赖。

### 3.4 签名配置

在模块级 `build.gradle.kts` 中配置签名：

```kotlin
android {
    signingConfigs {
        create("release") {
            storeFile = file("../keystore/zhuiju_release.jks")
            storePassword = System.getenv("ZHIUIU_STORE_PASSWORD")
            keyAlias = System.getenv("ZHIUIU_KEY_ALIAS")
            keyPassword = System.getenv("ZHIUIU_KEY_PASSWORD")
            enableV1Signing = true
            enableV2Signing = true
            enableV3Signing = true
        }
    }
    buildTypes {
        release {
            isMinifyEnabled = true
            isShrinkResources = true
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
            signingConfig = signingConfigs.getByName("release")
        }
    }
}
```

> **安全提示**：禁止将 keystore 密码硬编码进版本库，统一通过环境变量或 CI/CD 密钥管理注入。

### 3.5 ProGuard 混淆规则

`proguard-rules.pro` 必须保留以下核心类，避免功能失效：

```proguard
# ExoPlayer
-keep class androidx.media3.** { *; }

# FFmpeg
-keep class com.arthenica.ffmpegkit.** { *; }

# DanmakuFlameMaster
-keep class master.flame.danmaku.** { *; }

# OkHttp
-dontwarn okhttp3.**
-dontwarn okio.**

# 加密工具类（含 native 调用）
-keep class com.zhuiju.security.** { *; }
-keepclassmembers class com.zhuiju.security.** { *; }
```

### 3.6 debug / release 打包流程

#### 3.6.1 Debug 包（开发自测）

1. 在 Android Studio 中选择 `Build Variant = debug`。
2. 点击 `Run 'app'` 或执行命令：
   ```bash
   ./gradlew :app:assembleDebug
   ```
3. 产物路径：`app/build/outputs/apk/debug/app-debug.apk`。
4. Debug 包默认关闭混淆、开启日志、接入测试环境域名。

#### 3.6.2 Release 包（上线发布）

1. 配置好 `release` 签名与环境变量。
2. 执行命令：
   ```bash
   ./gradlew :app:assembleRelease
   ```
3. 产物路径：`app/build/outputs/apk/release/app-release.apk`。
4. Release 包强制开启混淆、资源压缩、关闭日志、关闭调试功能、接入正式环境域名。
5. 上线前需进行 **加签校验、混淆反编译自查、抓包验证无明文视频地址**。

## 四、首次启动流程

### 4.1 启动初始化流程图

```
APP 进程启动
   │
   ▼
Application.onCreate()
   │  - 初始化全局工具类（日志、吐司、异常捕获）
   │  - 初始化 OkHttpClient 单例
   │  - 初始化 ExoPlayer 全局管理器
   │  - 初始化 AES 加密工具与密钥管理器
   ▼
SplashActivity（启动页）
   │  - 展示启动动画 / 品牌 LOGO
   ▼
权限检查与申请（首次启动）
   │  - 申请存储权限（API ≤ 28）
   │  - 申请 READ_MEDIA_VIDEO（API 33+）
   ▼
拉取服务端动态密钥（AES-128-CBC）
   │  - 拉取临时密钥，有效期 24h
   │  - 密钥本地加密缓存
   ▼
首页数据预加载
   │  - 拉取短视频 Feed 流首页数据
   │  - 预加载前 3 个视频
   ▼
进入 MainActivity（首页短视频 Feed 流）
```

### 4.2 权限申请顺序

1. **首次启动**：申请 `INTERNET`、`ACCESS_NETWORK_STATE` 等普通权限（系统自动授予）。
2. **首次进入「我的 → 本地视频」**：申请存储 / `READ_MEDIA_VIDEO` 权限。
3. **首次进入「后台播放」**：申请 `FOREGROUND_SERVICE` 与 `POST_NOTIFICATIONS` 权限。
4. **首次进入「悬浮小窗」**：申请 `SYSTEM_ALERT_WINDOW` 权限。

每个权限申请均配置友好文案说明用途，用户拒绝后不强制阻断核心功能。

### 4.3 密钥拉取与缓存

- APP 启动后通过 OkHttp 向服务端发起密钥拉取请求，请求体携带设备指纹与签名。
- 服务端返回 AES-128-CBC 密钥与 IV，有效期 24 小时。
- 密钥经 Native 加密后缓存至本地 SharedPreferences，禁止明文存储。
- 后台运行超过 24 小时时，自动触发密钥刷新请求。

### 4.4 首页加载

- 首页采用懒加载，Fragment 可见时才请求短视频列表。
- 预加载策略：当前视频 + 前 1 个 + 后 1 个，共 3 个视频就绪。
- WiFi 网络下全额预加载，流量网络下仅预加载首帧以节省流量。

## 五、核心功能使用说明

### 5.1 长视频播放

#### 5.1.1 进入播放

- 在「发现页 / 排行榜 / 找片 / 我的」点击视频卡片 → 跳转长视频播放页。
- 播放页采用 FrameLayout 根布局（层级 ≤ 3）：TextureView → DanmakuView → 状态遮罩 → 控制栏 → 弹窗。

#### 5.1.2 基础操作

| 操作 | 触发方式 |
| --- | --- |
| 播放 / 暂停 | 点击画面中央 / 点击控制栏播放按钮 |
| 进度拖拽 | 横向拖拽进度条 / 横向滑动画布 |
| 倍速播放 | 点击控制栏「倍速」按钮，选择 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 1.75x / 2.0x |
| 静音切换 | 点击控制栏「音量」按钮 |
| 全屏切换 | 点击控制栏「全屏」按钮 / 设备旋转 |
| 选集 | 点击控制栏「选集」按钮弹出集列表 |
| 画质选择 | 全屏状态下点击「画质」按钮（720P / 1080P / 4K） |
| 缓存离线 | 点击控制栏「缓存」按钮加入下载队列 |

#### 5.1.3 手势控制（横屏全屏状态）

| 手势区域 | 手势方向 | 功能 |
| --- | --- | --- |
| 左侧半屏 | 上下滑动 | 调节屏幕亮度（实时浮窗提示） |
| 右侧半屏 | 上下滑动 | 调节音量（实时浮窗提示） |
| 全屏横向 | 左右滑动 | 拖拽播放进度（实时跳转时间提示） |
| 单次短点击 | — | 唤起 / 隐藏控制栏 |
| 长按 | — | 触发倍速临时 2x 播放（松手恢复） |

> 手势灵敏度：最小滑动判定距离 10dp，点击判定时长 200ms，长按判定 1000ms，杜绝误触发。

#### 5.1.4 横竖屏切换

- 横竖屏切换时 **不重建播放器实例**，仅适配 Surface 画布尺寸。
- 切换过程进度不丢失、控件位置不闪烁，搭配平滑缩放过渡动画。
- 适配刘海屏 / 挖孔屏：播放画面自动避开刘海区域。

#### 5.1.5 弹幕

- 弹幕层级：在视频画布之上、控制栏之下，禁止遮挡控制栏区域。
- 弹幕时间轴与播放进度精准同步：拖拽、倍速、暂停时弹幕同步刷新。
- 弹幕设置入口：点击控制栏「弹幕」按钮，弹出底部设置面板：
  - 弹幕开关
  - 字号（小 12sp / 默认 14sp / 大 16sp）
  - 透明度（0 ~ 1f，默认 0.8f）
  - 颜色（白 / 黄 / 红 / 绿 / 蓝）
  - 屏蔽类型（顶部 / 底部 / 关键词）
- 性能限制：单屏最大弹幕 80 条，低端机自动降级至 40 条并降低渲染帧率至 30fps。

#### 5.1.6 离线缓存

- 缓存路径：`/Android/data/<package>/files/video_cache/`（独立隔离目录，避免系统清理）。
- 缓存方式：ExoPlayer DownloadManager 分片下载，每分片 2MB，支持断点续传。
- 缓存加密：本地缓存文件二次 AES 加密存储，禁止明文落地。
- 缓存上限：5GB，达到 4.5GB 自动清理最早缓存。
- 缓存管理入口：「我的 → 离线缓存」可查看、清理缓存。

### 5.2 短视频 Feed 流

#### 5.2.1 进入短视频

- 「首页」即短视频 Feed 流，APP 启动默认进入。
- 「发现页」点击视频卡片 → 跳转短视频播放页（携带视频 ID 索引）。

#### 5.2.2 基础操作

| 操作 | 触发方式 | 说明 |
| --- | --- | --- |
| 上下切换 | 上下滑动画面 | ViewPager2 竖直滑动，无缝衔接无黑屏 |
| 播放 / 暂停 | 单击画面 | 唤起 / 隐藏右侧悬浮 UI |
| 点赞 | 双击画面 | 触发点赞粒子动画 |
| 评论 | 点击右侧「评论」按钮 | 评论弹窗侧滑出场 |
| 收藏 | 点击右侧「收藏」按钮 | 收藏动画反馈 |
| 分享 | 点击右侧「分享」按钮 | 调起系统分享面板 |
| 关注 | 点击右侧头像 / 关注按钮 | 关注作者 |
| 静音切换 | 点击右侧「音量」按钮 | 全局静音状态记忆 |

#### 5.2.4 播放策略

- 播放器池：3 个 ExoPlayer 实例（当前 + 上一个 + 下一个预加载），实现零黑屏切换。
- 首帧渲染：100ms 内完成首帧渲染。
- 静音自动播放：进入页面即静音播放，用户手动开启声音。
- 屏幕常亮：播放时保持屏幕常亮，退出页面关闭。
- 音频焦点：切后台或其他 APP 播放音频时自动暂停，恢复前台后自动续播。
- 低端机降级：CPU 核心数 < 4 时关闭播放器池，改用单实例 + 30fps 帧率锁定。

## 七、常见问题与故障排查

### 7.1 播放黑屏

| 可能原因 | 排查与解决 |
| --- | --- |
| TextureView 未及时渲染首帧 | 检查 `prepare()` 后是否调用 `play()`；确认 ExoPlayer 状态为 `STATE_READY` |
| SurfaceView 与 TextureView 混用层级冲突 | 统一使用 TextureView，禁止 SurfaceView 备选方案叠加 |
| 横竖屏切换时 Surface 重建异常 | 配置 `android:configChanges="orientation|screenSize|keyboardHidden"`，禁止 Activity 重建 |
| 加密分片解密失败 | 检查密钥是否过期，触发密钥刷新；验证 IV 偏移量配置 |

### 7.2 画面花屏

| 可能原因 | 排查与解决 |
| --- | --- |
| 硬解码兼容性问题 | 查看日志确认是否硬解失败，自动降级 FFmpeg 软解 |
| 视频编码不规范 | 使用 FFmpeg 转码修复异常视频 |
| 缓存分片损坏 | 清除该视频缓存重新下载 |
| 倍速播放导致解码丢帧 | 降低倍速档位，或限制最高倍速 2.0x |

### 7.3 播放卡顿 / 掉帧

| 可能原因 | 排查与解决 |
| --- | --- |
| 弱网环境缓冲不足 | 检查网络状态，提示用户切换 WiFi；增大初始缓冲至 5000ms |
| 弹幕数量过多 | 限制单屏最大弹幕 80 条，低端机降至 40 条并降低帧率 |
| 布局层级过深 | 检查播放页布局层级是否 ≤ 3，移除冗余嵌套 |
| 播放器实例泄漏 | 使用 LeakCanary 检测，确认页面销毁时 release 播放器 |
| 后台任务抢占 CPU | 暂停 FFmpeg 转码任务，确认子线程调度 |

### 7.4 无法播放

| 可能原因 | 排查与解决 |
| --- | --- |
| 视频链接失效 | 检查链接时效，触发密钥与服务端刷新链接 |
| 网络异常 | 提示用户检查网络，自动重试 3 次后展示错误页 |
| 解码失败 | 查看日志错误码，硬解失败自动降级软解 |
| 格式不兼容 | 确认支持 HLS / DASH / MP4 / FLV；其他格式走 FFmpeg 兜底 |
| 权限被拒 | 检查存储 / 网络权限是否授予，引导用户在设置中开启 |

### 7.5 缓存失败

| 可能原因 | 排查与解决 |
| --- | --- |
| 存储空间不足 | 检查设备可用空间，触发自动清理最早缓存 |
| 缓存目录被系统清理 | 确认缓存写入 `/Android/data/<package>/files/video_cache/`，遵循分区存储规范 |
| 断点续传超时 | 检查网络稳定性，超时 60s 后手动重试 |
| 加密写入失败 | 检查 AES 加密工具初始化是否成功，密钥是否过期 |
| 重复下载 | 通过 DownloadManager 去重，避免重复入队 |

### 7.6 弹幕不同步

| 可能原因 | 排查与解决 |
| --- | --- |
| 倍速切换未同步 | 确认弹幕时间轴工具类监听 `PlaybackParameters` 变化 |
| 拖拽进度未同步 | 拖拽完成后调用 `danmakuView.seekTo(currentPosition)` |
| 暂停状态弹幕继续 | 监听 `Player.STATE_PAUSED`，调用 `danmakuView.pause()` |
| 弹幕堆积 | 启用弹幕节流，限制单屏最大数量 |
| 时间戳异常 | 弹幕数据预处理过滤异常时间戳、重复数据 |

### 7.7 短视频切换黑屏 / 首帧慢

| 可能原因 | 排查与解决 |
| --- | --- |
| 播放器池未正确复用 | 确认 3 实例池预加载策略，检查 `offscreenPageLimit = 1` |
| 预加载未触发 | 检查页面静止时是否触发预加载，滑动中是否暂停多余预加载 |
| 首帧渲染未开启极速模式 | 关闭多余解码校验，首帧渲染控制在 100ms 内 |
| 内存压力释放不及时 | 滑动离开后延迟回收播放器，快速回滑无需重新加载 |

### 7.8 后台播放被杀

| 可能原因 | 排查与解决 |
| --- | --- |
| 未开启前台 Service | 确认 `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 类型已声明（API 34+） |
| 通知权限被拒 | 引导用户在设置中开启 `POST_NOTIFICATIONS` |
| 系统省电策略 | 引导用户将 APP 加入电池优化白名单 |
| WAKE_LOCK 未生效 | 确认 `WAKE_LOCK` 权限已授予，播放期间持有锁 |

### 8.3 抓包配置

#### 8.3.1 OkHttp 日志拦截器

```kotlin
val loggingInterceptor = HttpLoggingInterceptor().apply {
    level = if (BuildConfig.DEBUG) HttpLoggingInterceptor.Level.BODY
            else HttpLoggingInterceptor.Level.NONE
}
client.addInterceptor(loggingInterceptor)
```

#### 8.3.2 Charles / Fiddler 抓包

1. 在 Debug 包中配置 `network_security_config.xml` 允许明文流量与用户证书：

```xml
<!-- res/xml/network_security_config.xml -->
<network-security-config>
    <debug-overrides>
        <trust-anchors>
            <certificates src="user"/>
            <certificates src="system"/>
        </trust-anchors>
    </debug-overlays>
</network-security-config>
```

2. `AndroidManifest.xml` 中应用配置：

```xml
<application
    android:networkSecurityConfig="@xml/network_security_config"
    android:debuggable="true">
</application>
```

3. 设备安装抓包工具证书至「用户证书」。
4. **Release 包禁止**包含 `debug-overrides` 与 `debuggable=true`，防止抓包。

### 8.4 性能监控工具

- **LeakCanary**：Debug 包自动集成，检测 Activity / Fragment / 播放器内存泄漏。
- **StrictMode**：Debug 模式开启严苛模式，检测主线程 IO 与网络调用。
- **Choreographer**：通过 `Choreographer.FrameCallback` 监控帧率，低于 50fps 触发警告日志。
- **Profiler**：Android Studio Profiler 查看 CPU / 内存 / 网络实时占用。
